# 写教程

本技能用于为「Claude Code 新手学习项目」撰写或修订 `docs/` 下的教程。
目标：让产出的文档和现有 14 篇教程**风格一致、新手友好**。

## 写作约定（必须遵守）

1. **语言**：全部用**简体中文**，面向零基础新手，语气友好、避免黑话。
   首次出现的英文术语要给中文解释，例如「计划模式（Plan Mode）」。
2. **固定结构**：每篇教程依次包含四个部分——
   - **是什么**：一句话说清这个功能是什么。
   - **为什么**：为什么需要它、解决什么痛点。
   - **怎么用**：具体步骤、命令、快捷键；命令示例统一用 ```bash``` 代码块。
   - **动手试一试**：1～3 个可在本项目里立刻操作的练习。
3. **代码块**：一律标注语言；命令行示例用 `bash`。
4. **文内链接**：引用其它文档用**相对路径的 Markdown 链接**，方便点击跳转，
   例如 `[06 · 权限与安全](06-permissions.md)`。
5. **首尾导航**：文件开头用一行 `> 本节目标：……` 点明目标；
   文件结尾加一行上一节/下一节导航，与其它 docs 保持一致：
   `⬅️ 上一节：[xx](xx.md) ｜ ➡️ 下一节：[yy](yy.md)`。

## 工作流程

1. 先读 `CLAUDE.md` 确认最新写作约定，再挑一篇现有 `docs/` 教程（如
   [docs/07-plan-mode.md](../../../docs/07-plan-mode.md)）作为风格样板对照。
2. 文件名沿用 `编号-英文短名.md` 的命名（如 `15-xxx.md`），编号接续现有最大号。
3. 按上面「固定结构」四段式撰写。
4. 写完自检：四段是否齐全、术语是否有解释、代码块是否标了语言、
   首尾导航链接是否正确。

## 注意

- 这是纯学习项目，**不要**在教程里编造不存在的命令或功能；拿不准的先去核实。
- 不要去「修复」`exercises/sample-app/` 里**有意保留**的 bug。

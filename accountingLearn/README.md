# 中级会计职称备考学习手册

> 面向会计岗位从业者的中级会计师（中级会计职称）系统备考资料库
>
> 版本 v1.0 ｜ 整理日期 2026-10-30 ｜ 适用考季 2027 年（内容以财政部最新考试大纲、官方教材为准）

---

## 一、这个项目是什么

这是一套**纯 Markdown 的备考学习库**，不是题库，也不是教材的电子版，而是把三科教材知识重新组织成"**会计人能直接用来学和用**"的笔记：

- **按章节拆成独立文档**，每篇结构统一：考情 → 知识框架 → 核心考点 → 关键分录/公式 → 易错点 → 实务应用 → 自测题。
- **贴着会计岗位写**：每个考点尽量落到"这笔业务在实际做账时怎么处理"，而不是只背定义。
- **配套学习系统**：考试全景、三套备考计划、学习方法、打卡模板、错题本、考前冲刺清单。

适合人群：

| 人群 | 使用方式 |
| --- | --- |
| 在职会计，第一次考中级 | 从 `学习路径/00` 开始，选一套计划，按章节顺序学 |
| 考过一科，补考另一科 | 直接进对应科目文件夹，先看 `00-导学`，再攻薄弱章节 |
| 基础较弱（非科班/久未看书） | 实务从第 2 章存货起步，先补会计要素与分录基本功 |
| 临近考试（3 个月内） | 直接用 90 天计划 + `04-练习与冲刺/02-考前7天冲刺清单` |

## 二、三科怎么搭配

| 科目 | 特点 | 难度 | 建议投入 | 搭配建议 |
| --- | --- | --- | --- | --- |
| 中级会计实务 | 内容最多、综合性强、分录多 | ★★★★★ | 45% 时间 | 与财管同考（计算逻辑相通），不建议单独裸考 |
| 财务管理 | 公式多、计算量大、重理解 | ★★★★ | 30% 时间 | 与实务搭配最佳 |
| 经济法 | 记忆量大、案例化、性价比高 | ★★★ | 25% 时间 | 可单独报考，适合时间碎片化的人 |

**成绩管理**：三科在**连续 2 个考试年度内**全部合格即可取证（滚动有效）。因此常见策略是"**一年两科（实务+财管），第二年经济法**"或"**一年三科**"。

## 四、快速开始（4 步）

1. **先读** [`学习路径/00-考试全景与报名指南.md`](学习路径/00-考试全景与报名指南.md)，确认报考条件、时间节点和三科关系。
2. **选计划**：在 [`学习路径/01-备考计划-长线6个月90天.md`](学习路径/01-备考计划-长线6个月90天.md) 里选"长线 / 6 个月 / 90 天"其中一套，把周计划抄进日历。
3. **按章学**：从 `01-中级会计实务/00-导学与考情分析.md` 开始，每章按"先框架 → 再考点 → 后做题"推进，学完一章立刻做文末自测。
4. **建系统**：用 [`学习路径/03-每日打卡与复盘模板.md`](学习路径/03-每日打卡与复盘模板.md) 打卡，用 [`04-练习与冲刺/03-错题本模板.md`](04-练习与冲刺/03-错题本模板.md) 管错题。

> 不想逐个打开文件？见下方“网页浏览”，一条命令启动阅读页面，按目录连续看完全部 60 篇。

## 五、网页浏览（推荐）

项目自带一个阅读页面 `index.html`，比在文件夹里逐个点开 Markdown 更顺手。浏览器出于安全限制不能直接读取 `file://` 下的文档，需要先在**项目根目录**启动一个静态服务器：

```bash
cd F:\qorder-project\project4
python -m http.server 8080
```

然后浏览器访问 <http://localhost:8080>。没有 Python 也可以用 Node.js：

```bash
npx serve .
```

页面功能：

- **左侧目录**：按"开始 / 学习路径 / 实务 4 组 / 财管 / 经济法 / 练习冲刺"共 9 组排列，覆盖全部 60 篇文档；
- **搜索过滤**：目录上方的搜索框按章节名、路径即时筛选；
- **页内目录**：正文右侧自动提取二、三级标题，滚动时高亮当前小节（窄屏自动隐藏）；
- **连续阅读**：正文底部提供"上一篇 / 下一篇"，按备考顺序串联全部文档；
- **阅读设置**：右上角可切换深色模式、调整字号，选择会保存在浏览器本地；
- **离线可用**：解析库 `marked.min.js` 已放在本地，断网也能正常阅读。

> 如果双击 `index.html` 后正文提示"无法打开"，说明当前是 `file://` 方式，按上面的命令启动服务器即可。

## 六、文档使用约定

- **分值标注**：各章"预计分值"取自近年真题的平均值，仅供分配精力参考，实际以当年试卷为准。
- **分录写法**：统一用 `借：` / `贷：` 文本块，金额单位默认"元"，省略明细科目层级的会标注。
- **自测题**：答案放在 `<details>` 折叠块里，先做后看。
- **★ 标记**：★★★ 为必考核心，★★ 为常考，★ 为了解。
- **术语版本**：会计按《企业会计准则》及最新解释，法律按 2023 年修订《公司法》（2024-07-01 施行）、《民法典》、《增值税法》等现行规定编写；税率与优惠政策可能调整，**以当年官方口径为准**。

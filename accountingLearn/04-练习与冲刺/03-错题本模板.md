# 错题本模板

> **一句话**：错题本不是"抄题本"，而是**错误原因的诊断书**。一道错题只记三件事：**错在哪、为什么错、下次怎么防**。

---

## 一、错题本的核心字段

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| **编号** | 唯一标识，便于检索 | 实务-007 |
| **来源** | 真题/习题/模考 | 2024 真题单选 8 |
| **考点** | 对应章节和知识点 | 第 6 章 投资性房地产转换 |
| **题目摘要** | 一句话概括，不抄全题 | 公允价值模式转自用，差额去向 |
| **我的答案** | 记录当时的错误 | 计入其他综合收益 |
| **正确答案** | 标准答案 | 计入公允价值变动损益 |
| **错误类型** | 知识/方法/粗心 | 知识 |
| **错因分析** | 为什么会错 | 混淆"转换日差额"与"处置差额" |
| **正确思路** | 下次怎么做 | 转换日公允价值与账面价值差额→公允价值变动损益 |
| **复习记录** | 1/3/7/15 天 | 10-20 ✅ / 10-22 ✅ / 10-26 ✅ |

---

## 二、错误类型编码

```text
K = 知识性错误（概念不清、公式记错、法条记混）
M = 方法性错误（思路不对、步骤遗漏、不会拆题）
C = 粗心错误（看错数字、单位、借贷方向、漏选）
T = 时间性错误（会做但没时间、节奏失控）
```

> 统计时重点看 **K 和 M**——它们才是真正的漏洞；C 靠检查习惯解决，T 靠限时训练解决。

## 三、电子版模板（Markdown）

```markdown
## 错题 #实务-007

- **来源**：2024 年真题 单选 8
- **考点**：第 6 章 投资性房地产——转换
- **题目摘要**：公允价值模式计量的投资性房地产转为自用，转换日公允价值
  与账面价值的差额如何处理？
- **我的答案**：其他综合收益
- **正确答案**：公允价值变动损益
- **错误类型**：K（知识）
- **错因**：把"自用转投资性房地产（贷方差额→其他综合收益）"与
  "投资性房地产转自用（差额→公允价值变动损益）"记反了。
- **正确思路**：
  - 自用/存货 → 投资性房地产（公允价值模式）：借方差额→公允价值变动损益；
    贷方差额→其他综合收益。
  - 投资性房地产 → 自用：差额一律→公允价值变动损益。
- **关联题**：2023 真题多选 6、习题 6-3
- **复习记录**：10-20 ✅ ｜ 10-22 ✅ ｜ 10-26 ✅ ｜ 考前 ⬜
```

## 五、示例条目（三科各一）

### 实务

| 字段 | 内容 |
| --- | --- |
| 编号 | 实务-012 |
| 考点 | 第 17 章 所得税——暂时性差异 |
| 题目摘要 | 计提产品质量保证预计负债，是否产生暂时性差异 |
| 我的答案 | 不产生 |
| 正确答案 | 产生**可抵扣暂时性差异** |
| 错误类型 | K |
| 错因 | 只想到"负债账面价值 > 计税基础"，忘了预计负债计税基础为 0 |
| 正确思路 | 负债账面价值 > 计税基础 → 可抵扣暂时性差异 → 递延所得税资产 |

### 财管

| 字段 | 内容 |
| --- | --- |
| 编号 | 财管-005 |
| 考点 | 第 5 章 杠杆系数 |
| 题目摘要 | 已知 EBIT 和利息，求 DFL |
| 我的答案 | 用净利润作分子 |
| 正确答案 | DFL = EBIT ÷ (EBIT − I) |
| 错误类型 | K |
| 错因 | 公式记混，把 DFL 与"净利润变动率/EBIT 变动率"的推导混淆 |
| 正确思路 | 先写基期公式，再代入；DFL 分子是**基期 EBIT**，不是净利润 |

### 经济法

| 字段 | 内容 |
| --- | --- |
| 编号 | 经济法-009 |
| 考点 | 第 5 章 保证 |
| 题目摘要 | 保证合同未约定保证方式，债权人能否直接要求保证人还款 |
| 我的答案 | 能，连带责任保证 |
| 正确答案 | 不能，按**一般保证**，保证人有先诉抗辩权 |
| 错误类型 | K |
| 错因 | 按旧《担保法》思维作答 |
| 正确思路 | 《民法典》规定约定不明→一般保证；先诉抗辩权→先执行债务人财产 |

## 六、复习节奏：1-3-7-15

```text
错题当天：录入 + 写错因（10 分钟）
第 1 天：重做一遍，确认能独立做对
第 3 天：只看题目摘要，口述正确思路
第 7 天：遮住答案，完整重做
第 15 天：快速浏览，标记"仍不熟"的题
考前 7 天：只看"仍不熟"的题
```

> 每复习一次，在"复习记录"打勾；连续 3 次做对可以"毕业"，移出错题本。

### 3. 行动决策

- **K 类多** → 回教材/笔记重学该考点；
- **M 类多** → 练同类题的解题步骤，背模板；
- **C 类多** → 强制检查清单（单位、借贷、正负号）；
- **T 类多** → 限时套卷训练，练习取舍。

## 八、维护错题本的常见误区

1. **抄全题**——浪费时间，记"题目摘要 + 考点"即可；
2. **只抄答案不写错因**——下次还错；
3. **只加不复习**——错题本变成"收藏夹"；
4. **所有错题都记**——粗心题简单标记即可，重点记 K/M 类；
5. **不分类**——无法统计漏洞分布；
6. **考前才翻**——错过 1-3-7-15 的记忆节点；
7. **不做"毕业"管理**——错题本越来越厚，失去重点。

---

## 九、考前错题本使用法

```text
考前 7 天：只看标记"仍不熟"的题（约 20–30 道）
考前 3 天：看 K 类错题的"正确思路"一栏
考前 1 天：看自己写的"同类题识别标志"
进考场前：不再看新题，翻一遍错题本的目录即可
```

> 错题本是**越用越薄**的：真正掌握的题要果断移出，留下的是你最容易再犯的错。

# 每日打卡与复盘模板

> 打卡的意义不是"记录勤奋"，而是**让学习形成闭环**：计划 → 执行 → 记录 → 复盘 → 调整。建议直接复制本文表格到飞书/Notion/Excel，或打印成纸质表。

---

## 一、每日打卡表

### 模板（可直接复制）

```text
日期：2026-__-__（星期__）        距考试：___ 天
今日主题：______________________

【番茄钟】目标 4 个，实际 ___ 个
【学习时长】___ 小时 ___ 分钟

【今日完成】
1. 章节：________________  进度：第 __ 章 / 共 __ 章
2. 听课/看书：___ 节
3. 做题：单选 __ 道（对 __）多选 __ 道（对 __）判断 __ 道（对 __）
        主观题 __ 道（完成 __ 道）
4. 默写：分录 __ 条 / 公式 __ 个 / 法条 __ 条

【今日最大收获】
（一句话）____________________________________

【今日卡点】
（具体到知识点 + 为什么没懂）__________________

【明日第一件事】
____________________________________

状态自评：⭐⭐⭐⭐⭐（1–5 星）
```

### 极简版（忙碌日专用）

```text
__月__日 ✅ 学了 __ 分钟 ｜ 完成：__________ ｜ 卡点：__________
```

> 忙碌日允许"最低限度打卡"，但**不允许断更**。断一天，习惯就会断一周。

| 财管章节 | 第 __–__ 章 | 第 __–__ 章 | |
| 经济法章节 | 第 __–__ 章 | 第 __–__ 章 | |
| 做题量 | __ 道 | __ 道 | |
| 主观题 | __ 道 | __ 道 | |
| 学习时长 | __ 小时 | __ 小时 | |

**复盘四问**：

1. 本周**哪一天效率最高**？为什么？（复制那个状态）
2. 本周**哪个知识点反复错**？下周安排 30 分钟专项。
3. 本周**有哪些"假装学习"**（刷手机、抄书、只看视频）？下周怎么避免？
4. 下周计划是否需要调整？**只调整一次，改完就执行**。

## 三、月度复盘表（每月最后一个周末，30 分钟）

```text
【本月里程碑】
- 完成章节：______________________
- 真题成绩：实务 __ 分 ｜ 财管 __ 分 ｜ 经济法 __ 分
- 错题本新增：__ 道 ｜ 已消灭：__ 道

【数据看板】
- 打卡天数：__ / __ 天（出勤率 __%）
- 总学习时长：__ 小时（日均 __ 小时）
- 章节题正确率：__% → __%（变化）
- 主观题完成：__ 道

【三个问题】
1. 本月最大的进步是什么？
2. 本月最大的问题是什么？
3. 下月最重要的一件事是什么？

【下月计划微调】
（只改一处，例如：把经济法背诵挪到早晨）
```

## 四、学习记录示例（填好的样子）

```text
日期：2027-03-15（周一）        距考试：174 天
今日主题：长期股权投资——权益法损益调整

【番茄钟】目标 4 个，实际 3 个
【学习时长】2 小时 10 分钟

【今日完成】
1. 章节：第 5 章 长期股权投资  进度：第 5 章 / 共 26 章
2. 听课：2 节（权益法初始调整、损益调整）
3. 做题：单选 12 道（对 9）多选 6 道（对 3）判断 5 道（对 4）
        主观题 1 道（完成 1 道）
4. 默写：分录 6 条（初始投资成本调整、投资收益确认、其他综合收益）

【今日最大收获】
"初始投资成本小于享有份额的差额计入营业外收入"——本质是"买便宜了"。

【今日卡点】
内部交易未实现损益的调整方向老是搞反。错因：没有画"谁卖给谁"的图。
对策：以后每题先画箭头。

【明日第一件事】
做 3 道内部交易调整的专项题，做完讲一遍逻辑。

状态自评：⭐⭐⭐⭐
```

## 五、让打卡不断更的 5 个技巧

1. **固定触发点**：把学习绑定在固定动作后（如"洗完碗 → 坐下学 90 分钟"），不依赖意志力；
2. **降低启动门槛**：不想学时，只承诺"学 10 分钟"，通常开始后就会继续；
3. **可视化进度**：墙上贴一张 26 格的实务进度表，学完一章涂一格；
4. **设置补卡规则**：允许每月补卡 2 次，但补卡必须**双倍时长**；
5. **找一个监督人**：同事/考友每周互发进度截图，比自我承诺有效得多。

    ↑                        ↓

    ↓
调整下周计划（只改一处）

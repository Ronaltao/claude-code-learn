# 经济法数字与期限速记

> **用法**：考前每天早晚各过一遍；做题遇到数字题，先在本表定位章节，再回忆规则。
> **提醒**：数字以现行法律及当年教材为准，政策类期限（如小规模优惠）注意是否延续。

---

## 一、总论

| 数字 | 含义 |
| --- | --- |
| **8 周岁** | 限制民事行为能力的下限（8 周岁以上未成年人） |
| **18 周岁** | 完全民事行为能力 |
| **16 周岁** | 以自己劳动收入为主要生活来源的，视为完全民事行为能力人 |
| **30 日** | 相对人催告法定代理人/被代理人追认的期限 |
| **90 日** | **重大误解**撤销权行使期限 |
| **1 年** | 欺诈、显失公平、胁迫（自胁迫终止起）撤销权期限 |
| **5 年** | 撤销权最长保护期（自行为发生之日起） |
| **3 年** | 普通诉讼时效 |
| **20 年** | 诉讼时效最长保护期 |
| **6 个月** | 时效中止：最后 6 个月内发生障碍，消除后满 6 个月届满 |
| **15 日** | 不服**判决**的上诉期 |
| **10 日** | 不服**裁定**的上诉期 |
| **60 日** | 申请**行政复议** |
| **6 个月** | 直接提起**行政诉讼** |
| **15 日** | 经复议后起诉（收到复议决定书之日起） |

## 二、公司法律制度

| 数字 | 含义 |
| --- | --- |
| **1–50 人** | 有限责任公司股东人数 |
| **1–200 人** | 股份有限公司发起人人数 |
| **5 年** | 有限责任公司股东认缴出资缴足期限（自成立之日起） |
| **60 日** | 股东失权前的催缴宽限期（不少于） |
| **2/3** | 股东会特别决议表决权比例 |
| **过半数** | 股东会一般决议；董事会决议（全体董事过半数） |
| **3 人以上** | 董事会、监事会成员人数 |
| **1/3** | 监事会中职工代表比例（不少于） |
| **300 人** | 职工人数达到 300 人以上，董事会应有职工代表 |
| **30 日** | 股权对外转让，其他股东优先购买权答复期；法定代表人辞任后确定新代表人的期限 |
| **60 日 / 90 日** | 异议股东回购：60 日协商，90 日起诉 |
| **1 年** | 发起人持有的股份、上市前已发行股份的锁定期 |
| **25%** | 董监高每年转让股份上限（所持总数的） |
| **半年** | 董监高离职后不得转让股份的期限 |
| **10%** | 法定公积金提取比例（税后利润的） |
| **50%** | 法定公积金累计达注册资本 50% 可不再提取 |
| **25%** | 法定公积金转增资本后，留存比例不得低于转增前注册资本的 25% |
| **10 日 / 30 日** | 合并、减资：决议后 10 日通知债权人，30 日公告 |
| **30 日 / 45 日** | 债权人异议期：接到通知 30 日，未接到通知自公告 45 日 |
| **15 日** | 解散事由出现后成立清算组的期限 |
| **10 日 / 60 日** | 清算组：成立后 10 日通知，60 日公告 |
| **30 日 / 45 日** | 清算债权申报期 |
| **180 日 + 1%** | 股份有限公司股东代表诉讼的持股条件 |

## 三、合伙企业法律制度

| 数字 | 含义 |
| --- | --- |
| **2 人以上** | 普通合伙企业合伙人下限 |
| **2–50 人** | 有限合伙企业合伙人人数 |
| **1 人** | 有限合伙企业至少 1 个普通合伙人 |
| **30 日** | 有限合伙人对外转让份额，提前通知其他合伙人的期限 |
| **30 日** | 被除名人对除名决议有异议的起诉期 |
| **15 日 / 30 日 / 60 日** | 个人独资企业清算：清算前 15 日通知，债权人接到通知 30 日、未接到通知公告 60 日申报 |

## 四、金融法律制度

| 数字 | 含义 |
| --- | --- |
| **200 人** | 向特定对象发行累计超过 200 人，构成公开发行 |
| **4 个月** | 年度报告披露期限 |
| **2 个月** | 中期报告披露期限 |
| **5% / 3 日** | 持股达 5% 应在 3 日内报告、公告 |
| **5%** | 此后每增减 5% 再次报告公告 |
| **6 个月** | 短线交易禁止期（5% 股东、董监高） |
| **30–60 日** | 要约收购期限 |
| **30 日** | 保险人解除权行使期限（自知道解除事由起） |
| **2 年** | 保险合同不可抗辩期 |
| **30 日 / 60 日** | 人身保险宽限期：催告后 30 日，或约定期限 60 日 |
| **2 年** | 人身保险合同效力中止后的复效申请期 |
| **2 年 / 5 年** | 保险金请求权时效：一般 2 年，人寿保险 5 年 |
| **2 年** | 对票据出票人、承兑人的权利（自到期日/出票日） |
| **6 个月** | 对支票出票人的权利（自出票日） |
| **6 个月** | 对前手的追索权（自被拒绝承兑/付款日） |
| **3 个月** | 对前手的再追索权（自清偿日/被起诉日） |
| **10 日** | 支票提示付款期限 |
| **1 个月** | 见票后定期付款汇票提示承兑期限 |
| **3 日** | 付款人承兑或拒绝承兑的期限 |

## 五、合同法律制度

| 数字 | 含义 |
| --- | --- |
| **20%** | 定金不得超过主合同标的额的比例 |
| **6 个月** | 保证期间（没有约定或约定不明，自主债务履行期届满起） |
| **1 年 / 5 年** | 债权人撤销权：知道或应知撤销事由 1 年；行为发生 5 年 |
| **1 年** | 合同解除权行使期限（无约定时，自知道或应知解除事由起） |
| **1/5** | 分期付款买卖：未付到期价款达全部价款 1/5，可解除 |
| **20 年** | 租赁期限上限（超过部分无效） |
| **6 个月** | 租赁期限 6 个月以上应书面，否则视为不定期租赁 |
| **15 日** | 承租人优先购买权：通知后 15 日未表示视为放弃 |

## 六、增值税

| 数字 | 含义 |
| --- | --- |
| **500 万元** | 小规模纳税人与一般纳税人的年销售额分界 |
| **13%** | 货物、加工修理修配、有形动产租赁 |
| **9%** | 交通运输、邮政、基础电信、建筑、不动产租赁、销售不动产、转让土地使用权、农产品等 |
| **6%** | 现代服务、金融、生活服务、增值电信、无形资产（土地使用权除外） |
| **0%** | 出口货物、跨境服务 |
| **3%** | 小规模纳税人征收率 |
| **5%** | 不动产销售/租赁等简易计税征收率 |
| **10 万元 / 30 万元** | 小规模纳税人月销售额 10 万、季度 30 万以下免征（现行政策） |
| **1%** | 小规模纳税人 3% 征收率减按 1%（现行政策） |
| **15 日** | 按月/季纳税的申报期限 |
| **5 日** | 按日纳税的预缴期限 |

## 七、企业所得税

| 数字 | 含义 |
| --- | --- |
| **25%** | 基本税率 |
| **20%** | 小型微利企业税率（实际税负 5%） |
| **15%** | 高新技术企业、技术先进型服务企业 |
| **10%** | 非居民企业预提所得税 |
| **14%** | 职工福利费扣除限额（工资薪金总额） |
| **2%** | 工会经费扣除限额 |
| **8%** | 职工教育经费扣除限额（可结转） |
| **60% / 5‰** | 业务招待费：发生额 60% 与销售收入 5‰ 孰低 |
| **15% / 30%** | 广告费和业务宣传费：一般 15%，化妆品、医药、饮料制造 30%（可结转） |
| **12% / 3 年** | 公益性捐赠：利润总额 12%，超支结转 3 年 |
| **5%** | 补充养老、补充医疗保险扣除限额（各自） |
| **2:1 / 5:1** | 关联方债资比：一般 2:1，金融企业 5:1 |
| **5 年 / 10 年** | 亏损弥补：一般 5 年，高新/科技型中小企业 10 年 |
| **20 / 10 / 5 / 4 / 3 年** | 固定资产最低折旧年限：房屋、机器设备、器具、运输工具、电子设备 |
| **10 年** | 无形资产最低摊销年限 |
| **3 年** | 其他长期待摊费用最低摊销年限 |
| **300 万 / 300 人 / 5,000 万** | 小型微利企业三项条件 |
| **100% / 120%** | 研发费用加计扣除比例（一般/集成电路与工业母机） |
| **2 年 / 70%** | 创投企业投资未上市中小高新企业满 2 年，按投资额 70% 抵扣 |
| **15 日** | 预缴申报期限 |
| **5 个月** | 汇算清缴期限 |

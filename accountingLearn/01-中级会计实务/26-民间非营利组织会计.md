# 第 26 章 民间非营利组织会计

> **教材位置**：第 26 章 ｜ **预计分值**：1–2 分 ｜ **常考题型**：单选、多选、判断
> **一句话**：民非会计只记两件事——**净资产分"限定性/非限定性"**，**限制解除时重分类**。

---

## 一、知识框架

```text
民间非营利组织会计
├─ 特征（非营利、不取得回报、不享有所有权）
├─ 会计要素
│  ├─ 资产、负债、净资产
│  ├─ 收入（捐赠、会费、服务、商品销售、政府补助、投资）
│  └─ 费用（业务活动成本、管理费用、筹资费用、其他费用）
├─ 净资产
│  ├─ 限定性净资产
│  └─ 非限定性净资产
└─ 捐赠业务与限制解除
```

---

## 二、核心考点

### 考点 1：民非的特征与适用 ★★★

**特征**：

- 不以营利为目的；
- 资源提供者不取得经济回报；
- 资源提供者不享有所有权。

**适用对象**：社会团体、基金会、民办非企业单位、寺院教堂等。

> 民非**不核算利润**，期末将收入、费用结转至净资产。

### 考点 2：会计要素 ★★★★

| 类别 | 内容 |
| --- | --- |
| **资产** | 流动资产、长期投资、固定资产、无形资产等 |
| **负债** | 流动负债、长期负债 |
| **净资产** | **限定性净资产、非限定性净资产** |
| **收入** | 捐赠收入、会费收入、提供服务收入、商品销售收入、政府补助收入、投资收益 |
| **费用** | 业务活动成本、管理费用、筹资费用、其他费用 |

> **易错**：民非净资产**不分"实收资本/留存收益"**，只分限定性与非限定性。

### 考点 3：净资产分类 ★★★★★

| 类别 | 含义 |
| --- | --- |
| **限定性净资产** | 资产提供者或国家法律法规对资产的使用**设置了时间或用途限制** |
| **非限定性净资产** | 除限定性净资产以外的净资产 |

**限定性净资产的解除**：

- 限制条件**解除**时，将限定性净资产**重分类**为非限定性净资产；
- 分录：借"限定性净资产"，贷"非限定性净资产"。

> **注意**：限制解除是**净资产内部重分类**，**不确认收入**。

### 考点 4：捐赠业务 ★★★★★

```text
收到捐赠（限定性）：
借：银行存款
  贷：捐赠收入——限定性收入

期末结转：
借：捐赠收入——限定性收入
  贷：限定性净资产

限制解除：
借：限定性净资产
  贷：非限定性净资产
```

**非限定性捐赠**：

```text
收到时：
借：银行存款
  贷：捐赠收入——非限定性收入

期末：
借：捐赠收入——非限定性收入
  贷：非限定性净资产
```

**捐赠承诺**：一般**不确认**捐赠收入，实际收到时确认（附条件的捐赠在取得控制权时确认）。

### 考点 5：收入与费用的结转 ★★★

```text
期末：
借：捐赠收入 / 会费收入 / 提供服务收入 / 政府补助收入 / 投资收益等
  贷：限定性净资产 / 非限定性净资产

借：限定性净资产 / 非限定性净资产
  贷：业务活动成本 / 管理费用 / 筹资费用 / 其他费用
```

> 结转后，"收入""费用"科目无余额；净资产反映累计结余。

## 三、关键分录

```text
【收到非限定性捐赠】
借：银行存款
  贷：捐赠收入——非限定性收入
期末：
借：捐赠收入——非限定性收入
  贷：非限定性净资产

【收到限定性捐赠并期末结转】
借：银行存款
  贷：捐赠收入——限定性收入
期末：
借：捐赠收入——限定性收入
  贷：限定性净资产

【限制解除】
借：限定性净资产
  贷：非限定性净资产
```

## 四、例题

**例 26-1（限定性捐赠）**

某基金会收到一笔捐款 100 万元，捐赠协议约定用于资助贫困学生。当年实际资助支出 60 万元（限制已部分解除）。

```text
收到捐款：
借：银行存款                    100
  贷：捐赠收入——限定性收入        100

期末结转：
借：捐赠收入——限定性收入        100
  贷：限定性净资产                100

限制解除（60 万元）：
借：限定性净资产                  60
  贷：非限定性净资产                60
```

**例 26-2（非限定性捐赠）**

某协会收到一笔未指定用途的捐款 20 万元。

```text
借：银行存款                      20
  贷：捐赠收入——非限定性收入        20

期末：
借：捐赠收入——非限定性收入        20
  贷：非限定性净资产                20
```

## 五、易错点

1. **民非净资产分限定性/非限定性**，不是"实收资本/留存收益"。
2. **限定性净资产限制解除时要重分类**，不是直接转入收入。
3. **民非不核算利润**，期末将收入、费用结转至净资产。
4. **捐赠承诺一般不确认收入**，实际收到时确认。
5. **政府补助收入**在民非会计中单列，不适用企业政府补助准则。
6. 限定性净资产的限制包括**时间限制**和**用途限制**。

---

## 六、实务应用（会计岗位）

- **基金会/协会**：按捐赠协议区分限定性与非限定性，单独核算；
- **民办学校/医院**：按民非会计制度核算，不适用企业会计准则；
- **捐赠票据**：取得合规的公益事业捐赠票据，便于捐赠方税前扣除；
- **年度报告**：向登记管理机关报送财务报告，重点说明限定性净资产使用情况；
- **审计重点**：捐赠资金是否按约定用途使用、限制解除是否合规。

## 七、自测

**1.（判断）** 民间非营利组织的净资产分为限定性净资产和非限定性净资产。

**2.（单选）** 某基金会收到限定性捐赠 100 万元，期末结转时应贷记（ ）。
A. 非限定性净资产 B. 限定性净资产 C. 捐赠收入 D. 事业基金

**3.（单选）** 限定性净资产的限制解除时，应（ ）。
A. 确认捐赠收入 B. 转入非限定性净资产 C. 转入本期盈余 D. 冲减费用

**4.（多选）** 下列各项中，属于民间非营利组织收入的有（ ）。
A. 捐赠收入 B. 会费收入 C. 提供服务收入 D. 政府补助收入

<details>
<summary>参考答案与解析</summary>

1. **√**。
2. **B**。限定性捐赠期末结转至限定性净资产。
3. **B**。限制解除属于净资产内部重分类，不确认收入。
4. **ABCD**。还包括商品销售收入、投资收益。

</details>

# 第 6 章 投资性房地产

> **教材位置**：第 6 章 ｜ **预计分值**：3–5 分 ｜ **常考题型**：单选、多选、判断、计算分析
> **一句话**：本章核心是"**范围划得准 + 模式选得对 + 转换差额去向记得住**"。三种转换方向、两种计量模式，组合起来就是全部考点。

---

## 一、知识框架

```text
投资性房地产
├─ 范围（3 类）
├─ 初始计量（成本）
├─ 后续计量
│  ├─ 成本模式（折旧/摊销/减值）
│  └─ 公允价值模式（不折旧、公允价值变动损益）
├─ 后续支出（资本化 / 费用化）
├─ 转换（成本↔公允、自用/存货↔投资性房地产）
└─ 处置
```

---

## 二、核心考点

### 考点 1：范围 ★★★

**属于投资性房地产**：

1. **已出租的土地使用权**；
2. **持有并准备增值后转让的土地使用权**；
3. **已出租的建筑物**（企业拥有产权并以经营租赁方式出租）。

**不属于投资性房地产**：

| 项目 | 正确归类 |
| --- | --- |
| 自用房地产（自用办公楼、厂房） | 固定资产 / 无形资产 |
| 房地产开发企业作为存货的房地产 | 存货 |
| 空置建筑物（尚未出租） | 一般作为固定资产；但**董事会已作出书面决议明确将其用于经营出租且持有意图短期内不再变化**的，可作为投资性房地产 |
| 部分自用、部分出租的建筑物 | 能单独计量和出售的，分别确认；**不能单独计量的，全部作为固定资产** |

### 考点 2：后续计量模式 ★★★

| 项目 | 成本模式 | 公允价值模式 |
| --- | --- | --- |
| 折旧/摊销 | 计提 | **不计提** |
| 减值 | 计提，且**不得转回** | 不计提减值（公允价值变动已反映） |
| 期末价值变动 | — | 计入"**公允价值变动损益**" |
| 适用条件 | 默认模式 | ①投资性房地产所在地有**活跃的房地产交易市场**；②能够从市场上取得**同类或类似**房地产的市场价格及其他相关信息 |
| 模式变更 | 成本模式 → 公允价值模式：作为**会计政策变更**，追溯调整 | **公允价值模式 → 成本模式：不允许** |

### 考点 3：转换 ★★★★★

#### （1）成本模式下的转换

按账面价值对应结转，**不产生差额**：

- 投资性房地产 → 固定资产/无形资产：原值、累计折旧/摊销、减值准备对应转入；
- 固定资产/无形资产 → 投资性房地产：同上；
- 存货 → 投资性房地产：按账面价值转入"投资性房地产"。

#### （2）公允价值模式下的转换（重点）

| 转换方向 | 差额处理 |
| --- | --- |
| **投资性房地产 → 自用房地产/存货** | 公允价值与账面价值的差额计入**公允价值变动损益** |
| **自用房地产/存货 → 投资性房地产** | 公允价值 **>** 账面价值：差额计入**其他综合收益**<br>公允价值 **<** 账面价值：差额计入**公允价值变动损益** |

> 记忆口诀：**"转出去进损益，转进来涨了进 OCI、跌了进损益"**。
> 原因：防止企业通过"自用转投资性房地产"虚增利润（涨的部分先放 OCI，处置时才转损益）。

### 考点 4：后续支出 ★★

| 类型 | 判断 | 处理 |
| --- | --- | --- |
| 资本化 | 改建、扩建、装修，能增加未来经济利益 | 转入"投资性房地产——在建"，完工后转回；**期间不计提折旧/摊销** |
| 费用化 | 日常维修 | 计入"**其他业务成本**" |

### 考点 5：处置 ★★

- 收入计入"**其他业务收入**"；
- 账面价值结转"**其他业务成本**"；
- 公允价值模式下：
  - 原转换日计入**其他综合收益**的金额 → 转入"其他业务成本"；
  - 原累计**公允价值变动损益** → 转入"其他业务成本"（教材口径，使"其他业务成本"反映实际成本）。

## 三、关键分录

```text
【成本模式】
1. 计提折旧
借：其他业务成本
  贷：投资性房地产累计折旧

2. 取得租金
借：银行存款
  贷：其他业务收入
      应交税费——应交增值税（销项税额）

【公允价值模式】
3. 期末公允价值上升
借：投资性房地产——公允价值变动
  贷：公允价值变动损益（下降则相反）

4. 自用房地产转换为公允价值模式投资性房地产
借：投资性房地产——成本（公允价值）
    累计折旧
    固定资产减值准备
  贷：固定资产
      其他综合收益（公允价值 > 账面价值）
      公允价值变动损益（公允价值 < 账面价值的差额）

5. 处置（公允价值模式）
借：银行存款
  贷：其他业务收入
借：其他业务成本
  贷：投资性房地产——成本
      投资性房地产——公允价值变动（或借方）
借：其他综合收益
  贷：其他业务成本
借：公允价值变动损益
  贷：其他业务成本
```

## 四、例题

**例 6-1（自用转投资性房地产，公允价值上升）**

甲公司将自用办公楼转为投资性房地产，采用公允价值模式。转换日办公楼原值 5,000 万元，已提折旧 1,500 万元，公允价值 4,200 万元。

**解析**：账面价值 = 5,000 − 1,500 = 3,500（万元）；公允价值 4,200 > 3,500，差额 700 万元计入其他综合收益。

```text
借：投资性房地产——成本          4,200
    累计折旧                    1,500
  贷：固定资产                  5,000
      其他综合收益                700
```

**例 6-2（投资性房地产转自用，公允价值下降）**

承例 6-1，两年后甲公司将该办公楼收回自用。转换日投资性房地产账面价值 4,300 万元（其中成本 4,200 万元，公允价值变动借方余额 100 万元），当日公允价值 3,900 万元。

**解析**：差额 4,300 − 3,900 = 400（万元），计入公允价值变动损益。

```text
借：固定资产                    3,900
    公允价值变动损益              400
  贷：投资性房地产——成本        4,200
      投资性房地产——公允价值变动  100
```

**例 6-3（处置结转）**

承例 6-1（假设未发生例 6-2 的收回自用），甲公司以 4,500 万元出售该办公楼，原转换日确认的其他综合收益 700 万元尚未结转。

```text
借：银行存款                    4,500
  贷：其他业务收入              4,500

借：其他业务成本                4,200
  贷：投资性房地产——成本        4,200

借：其他综合收益                  700
  贷：其他业务成本                700
```

## 五、易错点

1. **公允价值模式不计提折旧、不摊销、不计提减值**。
2. **成本模式可以转公允价值模式（追溯调整），公允价值模式不能转成本模式**。
3. **转换差额去向**：转出（投房→自用/存货）进损益；转入（自用/存货→投房）涨了进 OCI、跌了进损益。
4. **空置建筑物**一般不算投资性房地产，除非董事会已作书面决议明确用于出租。
5. **部分自用部分出租且不能单独计量** → 全部作为固定资产。
6. 公允价值模式下**处置时其他综合收益要转入其他业务成本**，不是投资收益。
7. 投资性房地产的**日常维修费计入其他业务成本**（不是管理费用）。

---

## 六、实务应用（会计岗位）

- 企业持有出租写字楼、商铺，是投资性房地产的典型场景；
- 公允价值模式需要**活跃市场报价**支撑，一般企业（非上市公司）多采用成本模式；
- 模式一经选定，变更属于会计政策变更，需追溯调整并披露；
- 房产税、土地使用税与投资性房地产的持有成本相关，需与税务处理区分。

## 七、自测

**1.（单选）** 下列各项中，属于投资性房地产的是（ ）。
A. 自用办公楼
B. 房地产开发企业持有的待售商品房
C. 已出租的建筑物
D. 生产用厂房

**2.（判断）** 采用公允价值模式计量的投资性房地产，应当计提折旧。

**3.（单选）** 自用房地产转换为采用公允价值模式计量的投资性房地产，转换日公允价值大于账面价值的差额应计入（ ）。
A. 公允价值变动损益 B. 其他综合收益 C. 资本公积 D. 营业外收入

**4.（多选）** 下列关于投资性房地产后续计量模式的说法中，正确的有（ ）。
A. 成本模式可以转为公允价值模式
B. 公允价值模式可以转为成本模式
C. 成本模式转公允价值模式属于会计政策变更
D. 公允价值模式下不计提折旧

<details>
<summary>参考答案与解析</summary>

1. **C**。A、D 是固定资产，B 是存货。
2. **×**。公允价值模式不计提折旧、不摊销、不计提减值。
3. **B**。转入投资性房地产且公允价值大于账面价值，差额计入其他综合收益。
4. **ACD**。公允价值模式不能转回成本模式。

</details>

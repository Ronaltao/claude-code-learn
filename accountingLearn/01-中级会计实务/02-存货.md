# 第 2 章 存货

> **教材位置**：第 2 章 ｜ **预计分值**：3–5 分 ｜ **常考题型**：单选、多选、判断、计算分析
> **一句话**：存货考两件事——**入账成本里该装什么**（初始计量），和**跌价了怎么计提**（期末计量）。

---

## 一、知识框架

```text
存货
├─ 确认与初始计量
│  ├─ 采购成本 / 加工成本 / 其他成本
│  ├─ 不计入存货成本的支出
│  └─ 特殊来源（投资者投入、盘盈、非货币性交换等）
├─ 发出存货的计价方法
├─ 期末计量（成本与可变现净值孰低）
│  ├─ 可变现净值计算（商品 / 材料）
│  └─ 有合同 vs 无合同
└─ 存货跌价准备的计提、转回与结转
```

---

## 二、核心考点

### 考点 1：存货的初始计量 ★★★

**存货成本 = 采购成本 + 加工成本 + 其他成本**

| 构成 | 内容 |
| --- | --- |
| 采购成本 | 购买价款、相关税费、运输费、装卸费、保险费、运输途中的**合理损耗**、入库前的挑选整理费用 |
| 加工成本 | 直接人工、制造费用 |
| 其他成本 | 使存货达到目前场所和状态所发生的其他支出（如为特定客户设计产品的设计费） |

**不计入存货成本的支出**（高频考点）：

| 支出 | 处理 |
| --- | --- |
| 非正常消耗的直接材料、直接人工、制造费用 | 计入当期损益（自然灾害 → 营业外支出；管理不善 → 管理费用） |
| 采购入库**后**发生的仓储费用 | 计入管理费用 |
| 生产过程中为达到下一生产阶段所**必需**的仓储费用 | **计入存货成本** |
| 不能归属于使存货达到目前场所和状态的其他支出 | 计入当期损益 |
| 一般纳税人可抵扣的增值税进项税额 | 不计入（小规模纳税人计入） |

**特殊来源**：

- 投资者投入：按投资合同或协议约定的价值，**约定价值不公允的按公允价值**；
- 盘盈：按**重置成本**入账；
- 非货币性资产交换、债务重组取得：按相应准则确定。

> **商品流通企业**：采购商品过程中发生的运输费、装卸费、保险费等**计入存货采购成本**（现行准则），不再计入销售费用。

### 考点 2：发出存货的计价方法 ★★

- 先进先出法；
- 移动加权平均法；
- 月末一次加权平均法；
- 个别计价法。

> **不得采用后进先出法**（准则明确禁止）。

### 考点 3：期末计量——成本与可变现净值孰低 ★★★

**可变现净值 = 估计售价 − 至完工时估计将要发生的成本 − 估计的销售费用 − 相关税费**

**商品（可直接出售）**：

- 有合同部分：合同价 − 销售费用 − 税费；
- 无合同部分：市场价 − 销售费用 − 税费；
- **有合同与无合同部分分别计算，不能相互抵销**。

**材料**：

| 材料用途 | 可变现净值的确定 |
| --- | --- |
| 用于**出售**的材料 | 材料自身估计售价 − 销售费用 − 税费 |
| 用于**生产**产品的材料 | 先算产成品是否减值：<br>产成品未减值 → 材料按**成本**计量；<br>产成品减值 → 材料按可变现净值计量 = 产成品估计售价 − 至完工估计成本 − 销售费用 − 税费 |

> 记忆：**材料跟着产成品走**——产成品没跌，材料不跌；产成品跌了，材料才跌。

### 考点 4：存货跌价准备的计提、转回与结转 ★★★

- **计提**：成本 > 可变现净值，差额计提；
- **转回**：以前减记的因素消失，在**原已计提金额内**转回，计入当期损益；
- **结转**：存货销售时，同时结转已计提的跌价准备（冲减营业成本）。

## 三、关键分录

```text
1. 外购原材料（一般纳税人）
借：原材料
    应交税费——应交增值税（进项税额）
  贷：银行存款 / 应付账款

2. 计提存货跌价准备
借：资产减值损失
  贷：存货跌价准备

3. 跌价因素消失，转回（在原计提金额内）
借：存货跌价准备
  贷：资产减值损失

4. 销售存货，结转成本并结转跌价准备
借：主营业务成本
    存货跌价准备
  贷：库存商品

5. 盘亏（管理不善）
借：待处理财产损溢
  贷：原材料
      应交税费——应交增值税（进项税额转出）
批准后：
借：管理费用（一般经营损失）
    营业外支出（非常损失）
  贷：待处理财产损溢
```

## 四、例题

**例 2-1（可变现净值与跌价准备）**

甲公司期末库存 A 商品 100 件，单位成本 1,200 元，总成本 120,000 元。其中 40 件已签订销售合同，合同价 1,200 元/件；其余 60 件无合同，市场价 1,000 元/件。预计每件销售费用及相关税费 50 元。

要求：计算 A 商品应计提的跌价准备。

**解析**：

- 有合同部分可变现净值 = 40 ×（1,200 − 50）= 46,000（元）；成本 = 40 × 1,200 = 48,000（元）→ 减值 2,000 元；
- 无合同部分可变现净值 = 60 ×（1,000 − 50）= 57,000（元）；成本 = 60 × 1,200 = 72,000（元）→ 减值 15,000 元；
- 合计应计提跌价准备 = 2,000 + 15,000 = **17,000 元**。

```text
借：资产减值损失            17,000
  贷：存货跌价准备            17,000
```

**例 2-2（材料减值）**

乙公司库存 B 材料成本 100 万元，专门用于生产 C 产品。C 产品市场价 130 万元，将 B 材料加工成 C 产品尚需发生成本 40 万元，预计销售费用及税费 10 万元。B 材料市场价 95 万元。

**解析**：

- C 产品可变现净值 = 130 − 10 = 120（万元）；
- C 产品成本 = 100 + 40 = 140（万元）> 120，**C 产品减值**；
- B 材料可变现净值 = 130 − 40 − 10 = 80（万元），成本 100 万元 → 应计提跌价准备 **20 万元**。

> 注意：不能直接用 B 材料市场价 95 万元计算，因为材料是用于生产的。

## 五、易错点

1. **运输途中的合理损耗计入存货成本**，不扣除；非正常损耗才转出。
2. **采购入库后的仓储费计入管理费用**，只有"生产过程中为达到下一阶段所必需"的仓储费才计入存货成本。
3. **有合同和无合同部分分别计算减值**，不能合并后"互相弥补"。
4. **材料用于生产时，先判断产成品是否减值**，再决定材料是否减值。
5. **跌价准备转回以原计提金额为限**，不能转成"收益"。
6. 小规模纳税人采购存货，增值税**计入成本**。
7. 存货跌价准备**可以转回**（与固定资产、无形资产的减值不同）。

## 六、实务应用（会计岗位）

- **月末暂估入库**：货到票未到，按暂估价入账，次月初红字冲回；
- **存货盘点差异**：先记"待处理财产损溢"，查明原因后分别转管理费用/营业外支出/其他应收款（责任人赔偿）；
- **存货周转率**：期末存货计价直接影响毛利率和周转率，跌价准备计提是否充分是审计重点；
- **成本核算**：制造业的加工成本分摊（直接人工、制造费用）直接决定存货入账金额。

## 七、自测

**1.（单选）** 下列各项中，不应计入存货成本的是（ ）。
A. 运输途中的合理损耗
B. 入库前的挑选整理费用
C. 采购入库后发生的仓储费用
D. 为特定客户设计产品发生的设计费用

**2.（判断）** 企业计提的存货跌价准备，在以后期间不得转回。

**3.（单选）** 某材料专门用于生产甲产品，甲产品未发生减值，则该材料期末应按（ ）计量。
A. 成本
B. 可变现净值
C. 成本与可变现净值孰低
D. 公允价值

**4.（计算）** 丙公司库存商品成本 80 万元，预计售价 75 万元，预计销售费用及税金 3 万元，已计提跌价准备 5 万元。期末应计提（或转回）多少跌价准备？

<details>
<summary>参考答案与解析</summary>

1. **C**。采购入库后的仓储费用计入管理费用；生产过程中必需的仓储费才计入存货成本。
2. **×**。存货跌价准备在原计提金额内可以转回。
3. **A**。材料用于生产产品，产品未减值，材料按成本计量。
4. 可变现净值 = 75 − 3 = 72（万元），成本 80 万元，应保留跌价准备 8 万元；已计提 5 万元，**补提 3 万元**。
```text
借：资产减值损失        30,000
  贷：存货跌价准备        30,000
```

</details>

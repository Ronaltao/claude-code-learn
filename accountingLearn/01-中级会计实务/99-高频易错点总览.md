## 二、时间与期间类

| 事项 | 正确时间 |
| --- | --- |
| 固定资产折旧 | 当月增加**下月**提，当月减少**当月**照提 |
| 无形资产摊销 | 当月增加**当月**摊，当月减少**当月**不摊 |
| 投资性房地产（成本模式）折旧 | 比照固定资产 |
| 使用权资产折旧 | 租赁期开始日起计提 |
| 借款费用开始资本化 | 资产支出发生 + 借款费用发生 + 购建活动开始（同时满足） |
| 借款费用暂停资本化 | 非正常中断 + 连续超过 3 个月 |
| 借款费用停止资本化 | 达到预定可使用/可销售状态 |
| 持有待售 | 决议 + 确定购买承诺 + 一年内完成 |
| 日后事项期间 | 资产负债表日至**批准报出日** |
| 商誉减值测试 | 每年至少一次 |
| 使用寿命不确定的无形资产 | 每年减值测试，不摊销 |
| 辞退福利确认 | 不能单方面撤回时 / 确认重组成本时（孰早） |
| 股份支付等待期 | 授予日至可行权日 |

## 四、分类判断类

| 易混点 | 判断 |
| --- | --- |
| 合同资产 vs 应收账款 | 收款权是否仅取决于时间 |
| 保证类 vs 服务类质量保证 | 是否提供额外服务 |
| 主要责任人 vs 代理人 | 是否承担主要责任和存货风险 |
| 会计政策 vs 会计估计变更 | 基础/原则改变 vs 金额/比例估计改变 |
| 调整事项 vs 非调整事项 | 报表日是否已存在 |
| 融资租赁 vs 经营租赁（出租人） | 是否转移几乎全部风险和报酬 |
| 同一控制 vs 非同一控制 | 是否同受最终控制方控制 |
| 共同经营 vs 合营企业 | 对资产/负债享有权利 vs 对净资产享有权利 |
| 货币性 vs 非货币性项目 | 金额是否固定或可确定 |
| 终止经营 vs 持有待售 | 是否独立主要业务/地区或专为转售取得 |

## 五、计算陷阱类

1. **双倍余额递减法**：不扣残值，最后两年改直线；**年数总和法**扣残值。
2. **可变现净值**：材料用于生产时，先判断产成品是否减值。
3. **有合同/无合同存货**：分别计算，不能互相抵销。
4. **专门借款**：资本化金额 = 利息 − 闲置资金收益。
5. **一般借款**：资本化金额 = 支出加权平均数 × 资本化率。
6. **实际利率法**：利息收入 = 期初摊余成本 × 实际利率。
7. **权益法损益调整**：先调整公允价值口径，再抵销内部交易。
8. **资产组减值**：先冲商誉，再按比例分摊；分摊后不低于"公允减处置费用、现值、零"最高者。
9. **递延所得税**：资产账面 > 计税 → 应纳税差异；负债账面 > 计税 → 可抵扣差异。
10. **合并报表**：先权益法调整，再抵销；少数股东权益 = 净资产 × 少数比例。
11. **可转债**：负债成分按现值，权益成分倒挤。
12. **售后租回**：只确认转让给买方部分的利得。

# 中级会计实务 · 核心分录速查

> 考前默写用。金额用"__"代替，科目名称必须写全。默写完对照教材例题检查。

---

## 一、存货

```text
1. 外购原材料
借：原材料
    应交税费——应交增值税（进项税额）
  贷：银行存款 / 应付账款

2. 计提跌价准备
借：资产减值损失
  贷：存货跌价准备

3. 转回（原计提金额内）
借：存货跌价准备
  贷：资产减值损失

4. 销售结转
借：主营业务成本
    存货跌价准备
  贷：库存商品
```

---

## 二、固定资产

```text
1. 外购需安装
借：在建工程
    应交税费——应交增值税（进项税额）
  贷：银行存款
借：固定资产
  贷：在建工程

2. 计提折旧
借：制造费用 / 管理费用 / 销售费用等
  贷：累计折旧

3. 更新改造
借：在建工程
    累计折旧
    固定资产减值准备
  贷：固定资产

4. 处置
借：固定资产清理
    累计折旧
    固定资产减值准备
  贷：固定资产
借：固定资产清理
  贷：银行存款
借：银行存款
  贷：固定资产清理
      应交税费——应交增值税（销项税额）
借：固定资产清理
  贷：资产处置损益

5. 弃置费用
借：固定资产
  贷：预计负债
借：财务费用
  贷：预计负债
```

---

## 三、无形资产

```text
1. 研发支出
借：研发支出——费用化支出
    研发支出——资本化支出
  贷：银行存款 / 应付职工薪酬等

2. 期末结转
借：管理费用
  贷：研发支出——费用化支出

3. 研发完成
借：无形资产
  贷：研发支出——资本化支出

4. 摊销
借：管理费用 / 制造费用等
  贷：累计摊销

5. 出售
借：银行存款
    累计摊销
    无形资产减值准备
  贷：无形资产
      应交税费——应交增值税（销项税额）
      资产处置损益
```

---

## 四、投资性房地产

```text
1. 成本模式计提折旧
借：其他业务成本
  贷：投资性房地产累计折旧

2. 公允价值变动
借：投资性房地产——公允价值变动
  贷：公允价值变动损益

3. 自用转公允价值模式（升值）
借：投资性房地产——成本
    累计折旧
    固定资产减值准备
  贷：固定资产
      其他综合收益

4. 处置
借：银行存款
  贷：其他业务收入
借：其他业务成本
  贷：投资性房地产——成本
      投资性房地产——公允价值变动
借：其他综合收益
  贷：其他业务成本
```

---

## 五、长期股权投资

```text
1. 同一控制
借：长期股权投资
    资本公积——资本溢价（差额，或贷方）
  贷：银行存款 / 股本等

2. 非同一控制
借：长期股权投资
  贷：银行存款等

3. 权益法——初始调整（成本 < 份额）
借：长期股权投资——投资成本
  贷：银行存款
      营业外收入

4. 权益法——损益调整
借：长期股权投资——损益调整
  贷：投资收益

5. 权益法——其他综合收益
借：长期股权投资——其他综合收益
  贷：其他综合收益

6. 权益法——其他权益变动
借：长期股权投资——其他权益变动
  贷：资本公积——其他资本公积

7. 权益法——宣告分派现金股利
借：应收股利
  贷：长期股权投资——损益调整

8. 成本法——宣告分派现金股利
借：应收股利
  贷：投资收益

9. 处置
借：银行存款
  贷：长期股权投资
      投资收益
借：其他综合收益
    资本公积——其他资本公积
  贷：投资收益（或留存收益）
```

---

## 六、金融资产

```text
1. 交易性金融资产取得
借：交易性金融资产——成本
    投资收益（交易费用）
  贷：银行存款

2. 交易性金融资产公允价值变动
借：交易性金融资产——公允价值变动
  贷：公允价值变动损益

3. 债权投资计息
借：应收利息
    债权投资——利息调整
  贷：投资收益

4. 其他债权投资公允价值变动
借：其他债权投资——公允价值变动
  贷：其他综合收益

5. 其他债权投资减值
借：信用减值损失
  贷：其他综合收益

6. 其他权益工具投资处置
借：银行存款
  贷：其他权益工具投资——成本
      其他权益工具投资——公允价值变动
      盈余公积 / 利润分配——未分配利润
借：其他综合收益
  贷：盈余公积 / 利润分配——未分配利润
```

---

## 七、职工薪酬

```text
1. 自产产品发放福利
借：生产成本 / 管理费用等
  贷：应付职工薪酬
借：应付职工薪酬
  贷：主营业务收入
      应交税费——应交增值税（销项税额）
借：主营业务成本
  贷：库存商品

2. 辞退福利
借：管理费用
  贷：应付职工薪酬——辞退福利
```

## 八、借款费用

```text
1. 资本化利息
借：在建工程
    财务费用
  贷：应付利息 / 长期借款——应计利息

2. 闲置资金收益
借：银行存款
  贷：在建工程
```

## 九、或有事项

```text
1. 确认预计负债
借：营业外支出 / 管理费用 / 销售费用
  贷：预计负债

2. 实际发生
借：预计负债
  贷：银行存款 / 原材料等

3. 预期补偿（基本确定）
借：其他应收款
  贷：营业外支出
```

## 十、股份支付

```text
1. 权益结算——等待期
借：管理费用等
  贷：资本公积——其他资本公积

2. 权益结算——行权
借：银行存款
    资本公积——其他资本公积
  贷：股本
      资本公积——股本溢价

3. 现金结算——等待期
借：管理费用等
  贷：应付职工薪酬——股份支付

4. 现金结算——可行权日后公允价值变动
借：公允价值变动损益
  贷：应付职工薪酬——股份支付

5. 现金结算——行权
借：应付职工薪酬——股份支付
  贷：银行存款
```

---

## 十一、债务重组

```text
1. 债务人——以资产清偿
借：应付账款
  贷：固定资产清理 / 库存商品等
      应交税费——应交增值税（销项税额）
      其他收益——债务重组收益

2. 债务人——债转股
借：应付账款
  贷：股本
      资本公积——股本溢价
      投资收益

3. 债权人——受让资产
借：固定资产 / 库存商品等
    应交税费——应交增值税（进项税额）
    坏账准备
    投资收益（差额）
  贷：应收账款
```

---

## 十二、政府补助

```text
1. 与资产相关——总额法
借：银行存款
  贷：递延收益
借：递延收益
  贷：其他收益

2. 与资产相关——净额法
借：银行存款
  贷：递延收益
借：递延收益
  贷：固定资产

3. 与收益相关——补偿已发生
借：银行存款
  贷：其他收益
```

---

## 十三、非货币性资产交换

```text
1. 公允价值模式——换出固定资产
借：库存商品等
    应交税费——应交增值税（进项税额）
    银行存款（收到的补价）
  贷：固定资产清理
      应交税费——应交增值税（销项税额）
      资产处置损益

2. 账面价值模式
借：库存商品（按账面价值计算）
    应交税费——应交增值税（进项税额）
  贷：固定资产清理
      银行存款
```

---

## 十四、收入

```text
1. 预收款
借：银行存款
  贷：合同负债

2. 确认收入
借：合同负债 / 应收账款
  贷：主营业务收入
      应交税费——应交增值税（销项税额）

3. 建造合同（时段履约）
借：合同结算——收入结转
  贷：主营业务收入
借：主营业务成本
  贷：合同履约成本

4. 附退货条款
借：银行存款
  贷：主营业务收入
      预计负债——应付退货款
      应交税费——应交增值税（销项税额）
借：主营业务成本
    应收退货成本
  贷：库存商品
```

---

## 十五、所得税

```text
1. 当期所得税
借：所得税费用——当期所得税
  贷：应交税费——应交所得税

2. 递延所得税资产
借：递延所得税资产
  贷：所得税费用——递延所得税费用

3. 递延所得税负债
借：所得税费用——递延所得税费用
  贷：递延所得税负债

4. 计入其他综合收益
借：其他综合收益
  贷：递延所得税负债
```

## 十六、租赁

```text
1. 租赁期开始日
借：使用权资产
    租赁负债——未确认融资费用
  贷：租赁负债——租赁付款额
      银行存款（预付租金、初始直接费用）

2. 计提折旧
借：管理费用 / 制造费用等
  贷：使用权资产累计折旧

3. 确认利息
借：财务费用
  贷：租赁负债——未确认融资费用

4. 支付租金
借：租赁负债——租赁付款额
  贷：银行存款
```

## 十七、合并报表

```text
1. 权益法调整
借：长期股权投资
  贷：投资收益
      其他综合收益
      资本公积——其他资本公积

2. 抵销长投与所有者权益
借：股本
    资本公积
    盈余公积
    未分配利润——年末
    商誉
  贷：长期股权投资
      少数股东权益

3. 抵销投资收益与利润分配
借：投资收益
    少数股东损益
    未分配利润——年初
  贷：提取盈余公积
      对所有者（或股东）的分配
      未分配利润——年末

4. 内部存货交易抵销
借：营业收入
  贷：营业成本
      存货

5. 内部固定资产交易抵销
借：营业收入
  贷：营业成本
      固定资产
借：固定资产——累计折旧
  贷：管理费用
```

## 十八、差错与日后事项

```text
1. 前期差错更正
借：以前年度损益调整
  贷：累计折旧 / 预计负债等
借：应交税费——应交所得税
  贷：以前年度损益调整
借：利润分配——未分配利润
  贷：以前年度损益调整
借：盈余公积
  贷：利润分配——未分配利润

2. 日后调整事项（同上，通过"以前年度损益调整"）
```

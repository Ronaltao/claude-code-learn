# 第 7 章 资产减值

> **教材位置**：第 7 章 ｜ **预计分值**：2–4 分 ｜ **常考题型**：单选、多选、判断、计算分析
> **一句话**：本章记住两句话——**可收回金额取"卖价"和"用出来的现值"的较高者**；**减值一经计提，不得转回**。

---

## 一、知识框架

```text
资产减值
├─ 适用范围（哪些资产适用 / 不适用）
├─ 减值迹象（外部 / 内部）
├─ 可收回金额
│  ├─ 公允价值减去处置费用
│  └─ 预计未来现金流量现值
├─ 资产组（认定、减值分摊）
├─ 总部资产
├─ 商誉减值
└─ 账务处理（不得转回）
```

---

## 二、核心考点

### 考点 1：适用范围 ★★

**适用**《企业会计准则第 8 号——资产减值》的资产：

- 对子公司、联营企业、合营企业的**长期股权投资**；
- 采用**成本模式**计量的投资性房地产；
- **固定资产、无形资产**；
- **商誉**；
- 探明石油天然气矿区权益和井及相关设施；
- 使用权资产（按资产减值准则进行减值测试）。

**不适用**（由其他准则规范）：

| 资产 | 适用准则 |
| --- | --- |
| 存货 | 存货准则（可变现净值，可转回） |
| 金融资产 | 金融工具准则（预期信用损失） |
| 递延所得税资产 | 所得税准则 |
| 职工薪酬相关资产 | 职工薪酬准则 |
| 消耗性生物资产 | 生物资产准则 |

### 考点 2：减值迹象 ★★

| 外部迹象 | 内部迹象 |
| --- | --- |
| 资产市价大幅下跌 | 资产陈旧过时、实体损坏 |
| 技术、市场、经济、法律环境发生重大变化 | 资产闲置、终止使用、计划提前处置 |
| 市场利率或投资报酬率提高 | 资产经济绩效低于预期（现金流、利润远低于预算） |
| 所有者权益账面价值高于市值 | 内部报告显示资产可收回金额低于账面价值 |

> 只有**存在减值迹象**时才需进行减值测试；但**商誉、使用寿命不确定的无形资产、尚未达到可使用状态的无形资产**，**无论是否存在减值迹象，每年都必须进行减值测试**。

### 考点 3：可收回金额 ★★★

**可收回金额 = max（公允价值 − 处置费用，预计未来现金流量现值）**

| 项目 | 要点 |
| --- | --- |
| 公允价值 | 公平交易中销售协议价格；无协议价的，按市场价格；都没有的，以可获取的最佳信息为基础估计 |
| 处置费用 | 可直接归属于资产处置的**增量费用**（法律费用、相关税费、搬运费、直接使资产达到可销售状态的费用），**不包括**财务费用和所得税费用 |
| 预计未来现金流量 | 包括：资产持续使用过程中的现金流入、为实现现金流入所必需的现金流出、处置资产收到的净现金流量 |
| 折现率 | **税前**利率，反映当前市场货币时间价值和资产特定风险 |

**预计未来现金流量不包括**：

- 筹资活动产生的现金流量；
- 所得税收付产生的现金流量；
- 尚未作出承诺的**重组**、**改良**或**提高资产性能**的现金流量。

### 考点 4：资产组 ★★★

**认定**：企业可以认定的**最小资产组合**，其产生的现金流入应当**基本上独立于其他资产或资产组**产生的现金流入。

**减值分摊顺序**：

1. 先抵减**分摊至该资产组的商誉**的账面价值；
2. 再根据资产组中**除商誉外**其他各项资产的账面价值**所占比重**，按比例分摊；
3. 分摊后各资产的账面价值**不得低于**以下三者中的最高者：
   - 该资产的公允价值减去处置费用后的净额；
   - 该资产预计未来现金流量的现值；
   - 零。
   未能分摊的减值损失，再按比例分摊至其他资产。

### 考点 5：总部资产 ★★

- 能够**合理一致地分摊**至相关资产组的，分摊后连同资产组一起进行减值测试；
- **难以分摊**的，先在不考虑总部资产的情况下测试各资产组，再对总部资产进行组合测试。

### 考点 6：商誉减值 ★★★

- 商誉应**至少每年**进行减值测试；
- 自购买日起按合理方法**分摊至相关资产组**（或资产组组合）；
- 减值损失**先抵减商誉**，再按比例抵减其他资产；
- 商誉减值**不得转回**。

### 考点 7：账务处理 ★★

```text
借：资产减值损失
  贷：固定资产减值准备
      无形资产减值准备
      长期股权投资减值准备
      投资性房地产减值准备
      商誉减值准备
```

> **核心规则**：上述资产减值损失**一经计提，在以后会计期间不得转回**（与存货、金融资产不同）。

## 三、例题

**例 7-1（可收回金额）**

甲公司一台设备账面价值 1,000 万元。预计公允价值减去处置费用后的净额为 880 万元；预计未来现金流量现值为 920 万元。

**解析**：可收回金额 = max(880, 920) = **920 万元**；应计提减值 = 1,000 − 920 = **80 万元**。

```text
借：资产减值损失                80
  贷：固定资产减值准备            80
```

**例 7-2（资产组减值分摊）**

某资产组由 A、B、C 三项资产和商誉组成，账面价值分别为 400、300、200、100 万元，合计 1,000 万元。该资产组可收回金额为 700 万元，减值 300 万元。

**解析**：

1. 先抵减商誉 100 万元，剩余减值 200 万元；
2. 按 A、B、C 账面价值比例（400:300:200 = 4:3:2）分摊 200 万元：
   - A：200 × 4/9 ≈ 88.89 万元；
   - B：200 × 3/9 ≈ 66.67 万元；
   - C：200 × 2/9 ≈ 44.44 万元。
3. 分摊后 A、B、C 账面价值分别为 311.11、233.33、155.56 万元（均不低于各自可收回金额下限，无需二次调整）。

```text
借：资产减值损失                300
  贷：商誉减值准备                100
      固定资产减值准备——A          88.89
      固定资产减值准备——B          66.67
      固定资产减值准备——C          44.44
```

---

## 四、易错点

1. **可收回金额取较高者**，不是较低者。
2. **处置费用不含财务费用和所得税费用**；**未来现金流量不含筹资活动和所得税的现金流**。
3. **资产组减值先冲商誉**，再按比例分摊。
4. **减值不得转回**（固定资产、无形资产、长投、商誉、成本模式投资性房地产）。
5. **商誉每年必须减值测试**，不论是否有迹象。
6. 资产组分摊后**不得低于**"公允价值减处置费用、现值、零"三者最高者，超出部分二次分摊。
7. 折现率用**税前**利率。

---

## 五、实务应用（会计岗位）

- **年终减值测试**：固定资产、无形资产、商誉是审计重点，需留存减值测试底稿；
- **资产组划分**：制造企业通常按生产线划分资产组，与预算、考核口径保持一致；
- **商誉减值**：并购形成的商誉，一旦减值直接冲击利润，需关注被收购业务的实际业绩；
- **不得转回的意义**：防止企业通过"先减值后转回"调节利润。

## 六、自测

**1.（单选）** 资产可收回金额应当根据（ ）确定。
A. 公允价值减去处置费用后的净额
B. 预计未来现金流量现值
C. 两者中的较高者
D. 两者中的较低者

**2.（判断）** 固定资产减值损失在以后期间可以转回。

**3.（单选）** 资产组减值损失应当首先抵减（ ）。
A. 固定资产 B. 无形资产 C. 商誉 D. 按比例分摊

**4.（多选）** 下列现金流量中，不应包括在资产预计未来现金流量中的有（ ）。
A. 资产持续使用产生的现金流入
B. 筹资活动产生的现金流量
C. 所得税收付产生的现金流量
D. 尚未承诺的重组产生的现金流量

<details>
<summary>参考答案与解析</summary>

1. **C**。取公允价值减处置费用与现值中的较高者。
2. **×**。资产减值损失一经计提不得转回。
3. **C**。先抵减商誉，再按比例分摊其他资产。
4. **BCD**。A 属于应包含的现金流量。

</details>

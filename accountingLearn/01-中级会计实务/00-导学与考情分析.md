# 中级会计实务 · 导学与考情分析

> 本科目是三科中内容最多、主观题分值最高的一科。**得主观题者得实务**。

---

## 一、科目特点

| 特点 | 说明 | 应对 |
| --- | --- | --- |
| 内容多 | 26 章，覆盖资产、负债、收入、报表、特殊业务 | 抓重点章节，低频章只求"会判断" |
| 综合性强 | 综合题常跨 2–3 章（长投+合并、收入+所得税、租赁+固定资产） | 学完单章后做跨章题 |
| 分录是命脉 | 主观题本质是"写对分录 + 算对金额" | 每章默写典型分录 |
| 准则导向 | 答案必须符合《企业会计准则》表述 | 记准科目名称与差额去向 |
| 与工作强相关 | 大部分内容就是日常核算 | 用工作中的业务反推准则 |

- 小计算题（债务重组、非货币性资产交换、政府补助、借款费用）常出计算分析题，性价比极高。

## 三、题型策略

| 题型 | 策略 |
| --- | --- |
| 单选（15 分） | 基础概念 + 小计算，争取 12 分以上 |
| 多选（20 分） | 最容易失分，宁可少选不要错选（多选、错选不得分，少选得部分分） |
| 判断（10 分） | 答错倒扣 0.5 分；完全不会时蒙一个期望为正（+0.25 分），不要留空 |
| 计算分析（22 分） | 写出计算过程，分步得分；分录题科目名写全 |
| 综合（33 分） | 先做会的小问，难题先写框架；即使不会也要写"借/贷"和相关科目 |

**时间分配（165 分钟）**：

- 客观题 45 分钟；
- 计算分析题 35 分钟；
- 综合题 75 分钟；
- 检查 10 分钟。

## 四、学习顺序建议

```text
第1章 总论（打地基）
   ↓
存货 → 固定资产 → 无形资产 → 投资性房地产（资产基础四件套）
   ↓
金融资产 → 长期股权投资（金融工具与权益投资）
   ↓
收入 → 所得税 → 租赁（三大重点准则）
   ↓
债务重组 / 非货币性资产交换 / 政府补助 / 借款费用 / 或有事项 / 股份支付（小专题）
   ↓
企业合并 → 合并财务报表（终极 BOSS，建议放在财管学完后再攻）
   ↓
政策变更 / 日后事项 / 外币 / 持有待售 / 政府会计 / 民非（收尾）
```

**不建议**按教材顺序从第 1 章一路硬啃到第 26 章，容易在长投、合并处卡死而失去信心。先把"资产四件套"学扎实，建立正反馈。

## 五、与其他两科的关系

| 关联点 | 说明 |
| --- | --- |
| 实务 ↔ 财管 | 货币时间价值（现值）是租赁、固定资产分期付款、弃置费用的计算基础 |
| 实务 ↔ 经济法 | 公司法、合同法影响会计主体与交易实质判断；所得税一章与税法高度重合 |
| 与工作 | 存货、固定资产、收入、职工薪酬几乎就是日常账务，学的时候对照自己做过的凭证 |

## 六、常见误区

1. **只背分录不理解准则**：题目稍微变形就不会；
2. **跳过例题直接刷题**：教材例题是最好的"标准答案模板"；
3. **合并报表留到最后一周**：这章至少需要 2–3 周反复消化；
4. **不做主观题**：客观题会做不代表会写分录，主观题占 55 分；
5. **忽视小专题**：债务重组、非货币性资产交换、政府补助每年稳定出计算题，投入产出比最高。

## 七、本章学习法

每章按固定动作走一遍：

1. 看"知识框架"，知道本章有几块；
2. 精读"核心考点"，每个考点配一道例题；
3. **默写"关键分录"**；
4. 扫一遍"易错点"；
5. 做"自测"，错题写进错题本；
6. 在打卡表上涂掉一格。

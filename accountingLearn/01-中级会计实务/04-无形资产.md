# 第 4 章 无形资产

> **教材位置**：第 4 章 ｜ **预计分值**：2–3 分 ｜ **常考题型**：单选、多选、判断
> **一句话**：无形资产考三件事——**研发支出怎么分**（研究/开发）、**摊销怎么算**（寿命有限/不确定）、**土地使用权怎么归类**。

---

## 一、知识框架

```text
无形资产
├─ 确认与初始计量（外购、投资者投入、政府补助取得、土地使用权）
├─ 内部研究开发支出（研究阶段 / 开发阶段）
├─ 后续计量
│  ├─ 使用寿命有限：摊销（方法、残值、期限）
│  └─ 使用寿命不确定：不摊销，每年减值测试
├─ 处置与报废
└─ 土地使用权（自用 / 开发 / 出租）
```

---

## 二、核心考点

### 考点 1：确认与初始计量 ★★

**定义**：企业拥有或控制的**没有实物形态**的**可辨认非货币性资产**。

> "可辨认"：能够从企业中分离或划分出来，并能单独或与相关合同、资产、负债一起用于出售、转移、授予许可、租赁或交换；**或者**源于合同性权利或其他法定权利。

**初始计量**：

| 来源 | 成本 |
| --- | --- |
| 外购 | 购买价款 + 相关税费 + 直接归属于使该项资产达到预定用途所发生的其他支出（如专业服务费、测试费） |
| 投资者投入 | 合同/协议约定价值，不公允的按公允价值 |
| 政府补助取得 | 按公允价值；公允价值不能可靠取得的，按名义金额（1 元） |
| 分期付款 | 按购买价款现值入账 |

> 注意：**广告费、管理费用等间接费用不计入无形资产成本**；**为引入新产品进行宣传的广告费**计入当期损益。

### 考点 2：内部研究开发支出 ★★★

| 阶段 | 处理 |
| --- | --- |
| **研究阶段** | 全部**费用化**，计入"研发支出——费用化支出"，期末转入管理费用 |
| **开发阶段** | 符合资本化条件的，计入"研发支出——资本化支出"，达到预定用途时转入无形资产；不符合的，费用化 |
| 无法区分研究阶段和开发阶段 | **全部费用化** |

**开发阶段资本化的 5 个条件**（同时满足）：

1. 完成该无形资产以使其能够使用或出售在技术上具有**可行性**；
2. 具有完成该无形资产并使用或出售的**意图**；
3. 无形资产产生经济利益的**方式**（包括能够证明运用该无形资产生产的产品存在市场或无形资产自身存在市场）；
4. 有足够的**技术、财务资源和其他资源**支持，以完成该无形资产的开发，并有能力使用或出售该无形资产；
5. 归属于该无形资产开发阶段的支出能够**可靠地计量**。

### 考点 3：摊销 ★★★

| 项目 | 规定 |
| --- | --- |
| 使用寿命有限 | 在使用寿命内**系统合理摊销**；通常按直线法，也可按产量法等 |
| 使用寿命不确定 | **不摊销**，但**每个会计期末进行减值测试** |
| 摊销起点 | **当月增加，当月开始摊销；当月减少，当月不再摊销**（与固定资产相反） |
| 残值 | 一般**假定为零**（除有第三方承诺购买、或活跃市场存在等情形） |
| 摊销科目 | 一般计入"累计摊销"；生产产品使用的计入"制造费用"，管理用计入"管理费用"等 |

> **与固定资产对比**：无形资产"当月增当月摊，当月减当月不摊"；固定资产"当月增下月提，当月减当月照提"。

### 考点 4：处置 ★

- 出售：差额计入"**资产处置损益**"；
- 报废：差额计入"**营业外支出**"（如已无使用价值和转让价值）；
- 出租：租金计入"其他业务收入"，摊销计入"其他业务成本"。

### 考点 5：土地使用权 ★★★

| 用途 | 确认科目 |
| --- | --- |
| 自用（建造厂房等） | **无形资产**（土地使用权） |
| 房地产开发企业开发商品房 | **存货**（开发成本） |
| 出租 / 持有并准备增值后转让 | **投资性房地产** |
| 外购房屋建筑物（价款在土地和建筑物之间无法合理分配） | **全部作为固定资产** |
| 外购房屋建筑物（能合理分配） | 分别确认为无形资产（土地）和固定资产（建筑物） |

## 三、关键分录

```text
1. 发生研发支出
借：研发支出——费用化支出
    研发支出——资本化支出
  贷：银行存款 / 应付职工薪酬 / 原材料等

2. 期末结转费用化支出
借：管理费用
  贷：研发支出——费用化支出

3. 研发完成，结转资本化支出
借：无形资产
  贷：研发支出——资本化支出

4. 计提摊销（管理用）
借：管理费用
  贷：累计摊销

5. 出售无形资产
借：银行存款
    累计摊销
    无形资产减值准备
  贷：无形资产
      应交税费——应交增值税（销项税额）
      资产处置损益（或借方）
```

## 四、例题

**例 4-1（研发支出）**

甲公司 2027 年研发一项专利技术，研究阶段支出 200 万元，开发阶段支出 500 万元（其中符合资本化条件的 300 万元），年末研发完成并达到预定用途。

**解析**：

- 费用化金额 = 200 +（500 − 300）= 400（万元），计入管理费用；
- 资本化金额 = 300（万元），转入无形资产；
- 若该专利使用寿命 10 年，无残值，直线法摊销，则当年（假设 12 月达到用途，当月开始摊销）摊销 2.5 万元。

```text
借：无形资产                        300
  贷：研发支出——资本化支出          300

借：管理费用                        400
  贷：研发支出——费用化支出          400
```

**例 4-2（土地使用权归类）**

乙公司购入一宗土地使用权，支付价款 5,000 万元，用于建造自用办公楼。应确认为（ ）。

**答案**：**无形资产**。自用土地按无形资产核算，建造的办公楼单独作为固定资产。

## 五、易错点

1. **摊销起点与固定资产相反**：无形资产"当月增加当月摊"，固定资产"下月提"。
2. **研究阶段支出全部费用化**，开发阶段只有满足 5 个条件才资本化。
3. **无法区分研究/开发阶段的，全部费用化**。
4. **使用寿命不确定的无形资产不摊销，但每年必须减值测试**。
5. **土地使用权**：自用→无形资产；房企开发→存货；出租→投资性房地产；外购房屋无法分配→全部固定资产。
6. **无形资产的减值不得转回**（与存货不同）。
7. 内部研发无形资产的成本**不包括**：培训费、广告费、其他间接费用、已费用化的支出。

---

## 六、实务应用（会计岗位）

- **研发费用加计扣除**：会计上费用化的研发支出，税务上可享受加计扣除（现行 100%），需要"研发支出辅助账"支撑；
- **高新企业认定**：研发费用占比是核心指标，账务归集要规范；
- **软件企业**：外购软件、自行开发软件的入账与摊销政策影响利润；
- **土地使用权**：工业企业自用土地摊销计入"管理费用"或"制造费用"（厂房占地），影响产品成本。

## 七、自测

**1.（单选）** 甲公司 2027 年 5 月取得一项专利权，当月开始使用，预计使用寿命 10 年。该专利权 2027 年应摊销（ ）个月。
A. 7 B. 8 C. 10 D. 12

**2.（判断）** 使用寿命不确定的无形资产不需要摊销，也不需要减值测试。

**3.（多选）** 下列支出中，应计入自行研发无形资产成本的有（ ）。
A. 研究阶段支出
B. 开发阶段符合资本化条件的支出
C. 开发阶段不符合资本化条件的支出
D. 研发过程中使用的材料费（资本化部分）

**4.（单选）** 房地产开发企业取得用于建造商品房的土地使用权，应确认为（ ）。
A. 无形资产 B. 固定资产 C. 存货 D. 投资性房地产

<details>
<summary>参考答案与解析</summary>

1. **B**。5 月取得，当月开始摊销，5–12 月共 8 个月。
2. **×**。不摊销，但**每年年末必须进行减值测试**。
3. **BD**。研究阶段全部费用化；开发阶段只有符合资本化条件的才计入成本。
4. **C**。房企开发商品房用的土地计入开发成本（存货）。

</details>

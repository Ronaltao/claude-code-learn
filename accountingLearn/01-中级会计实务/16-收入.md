# 第 16 章 收入

> **教材位置**：第 16 章 ｜ **预计分值**：8–12 分 ｜ **常考题型**：单选、多选、判断、计算分析、综合
> **一句话**：收入准则只有一个框架——**五步法**；所有特殊交易（质量保证、主要责任人、售后回购、建造合同）都是五步法的应用。

---

## 一、知识框架

```text
收入
├─ 五步法
│  ├─ 1. 识别与客户订立的合同
│  ├─ 2. 识别合同中的单项履约义务
│  ├─ 3. 确定交易价格
│  ├─ 4. 将交易价格分摊至各单项履约义务
│  └─ 5. 履行履约义务时确认收入（时段 / 时点）
├─ 合同成本（履约成本、取得成本）
├─ 特殊交易
│  ├─ 质量保证
│  ├─ 主要责任人 / 代理人
│  ├─ 附退货条款
│  ├─ 授予知识产权许可
│  ├─ 售后回购
│  └─ 建造合同（时段履约）
└─ 列报（合同资产、合同负债、应收账款）
```

---

## 二、核心考点

### 考点 1：五步法总览 ★★★★★

| 步骤 | 核心问题 | 关键判断 |
| --- | --- | --- |
| 1. 识别合同 | 合同是否成立 | 5 个条件同时满足 |
| 2. 识别履约义务 | 有几项义务 | 商品是否**可明确区分** |
| 3. 确定交易价格 | 能收多少钱 | 可变对价、重大融资成分、非现金对价、应付客户对价 |
| 4. 分摊交易价格 | 每项义务值多少 | 按**单独售价相对比例**分摊 |
| 5. 确认收入 | 什么时候确认 | **时段**（3 个条件之一）或**时点**（控制权转移） |

### 考点 2：合同成立的条件 ★★★

同时满足：

1. 合同各方**已批准**该合同并承诺将履行各自义务；
2. 该合同**明确了各方的权利和义务**；
3. 该合同**有明确的支付条款**；
4. 该合同**具有商业实质**；
5. 企业**很可能收回**因向客户转让商品而有权取得的对价。

> 不满足的，只有满足下列之一才确认收入：①已收取的对价无需退回且合同已终止；②已转让商品且几乎全部对价已收取且无需退回。

### 考点 3：单项履约义务 ★★★★

**可明确区分**（同时满足）：

1. 客户能够从该商品本身或从该商品与其他易于获得资源一起使用中**受益**；
2. 企业向客户转让该商品的承诺与合同中其他承诺**可单独区分**。

**常见情形**：

- 销售设备 + 安装服务：安装不复杂 → 一项履约义务；安装高度复杂 → 两项；
- 销售软件 + 一年免费升级：通常两项；
- 提供重大整合服务 → 整体作为一项履约义务。

### 考点 4：交易价格 ★★★★★

| 因素 | 处理 |
| --- | --- |
| **可变对价** | 按**期望值**或**最可能发生金额**确定，计入交易价格的可变对价金额**不得超过**在相关不确定性消除时**累计已确认收入极可能不会发生重大转回**的金额（限制条件） |
| **重大融资成分** | 合同存在重大融资成分的，按**现销价格**确定交易价格，差额按实际利率法摊销（时间间隔不超过 1 年的，可不考虑） |
| **非现金对价** | 按**公允价值**确定；不能可靠计量的，按**商品单独售价**间接确定 |
| **应付客户对价** | 冲减交易价格（除非该对价是为了取得**可明确区分**的商品/服务） |

### 考点 5：分摊交易价格 ★★★★

- 按各单项履约义务的**单独售价相对比例**分摊；
- 单独售价无法直接观察的，合理估计（市场调整法、成本加成法、余值法）；
- **合同折扣**：通常按比例分摊至各履约义务；有证据表明仅与一项或部分相关时，分摊至相关部分；
- **可变对价**：通常分摊至全部履约义务；仅与某一项相关时，分摊至该项。

### 考点 6：时段履约 vs 时点履约 ★★★★★

**属于时段履约**（满足其一）：

1. 客户在企业履约的同时**即取得并消耗**企业履约所带来的经济利益（如物业服务）；
2. 客户能够**控制**企业履约过程中**在建商品**（如在客户土地上建造厂房）；
3. 企业履约过程中所产出的商品具有**不可替代用途**，且企业在整个合同期间内**有权就累计至今已完成的履约部分收取款项**。

**时段履约的进度确认**：

- **投入法**：按已发生成本占预计总成本的比例（最常见）；
- **产出法**：按已转移商品/已提供服务占总量比例。

**时点履约**：在客户**取得相关商品控制权**时确认收入。控制权转移的迹象：

- 企业享有**现时收款权利**；
- 客户已取得商品**法定所有权**；
- 企业已将商品**实物转移**给客户；
- 客户已取得商品**所有权上的主要风险和报酬**；
- 客户已**接受**该商品。

### 考点 7：质量保证 ★★★★

| 类型 | 判断 | 处理 |
| --- | --- | --- |
| **保证类**（法定质量保证） | 保证商品符合既定标准 | 按**或有事项**处理（预计负债） |
| **服务类**（额外服务） | 单独提供服务 | 作为**单项履约义务**，分摊交易价格，在服务期间确认收入 |

> 无法区分的，**按保证类**处理。

### 考点 8：主要责任人 vs 代理人 ★★★★

| 角色 | 判断迹象 | 收入确认 |
| --- | --- | --- |
| **主要责任人** | 承担商品的主要责任、承担存货风险、有定价权 | **总额法**（按收取的全部价款确认收入） |
| **代理人** | 不承担主要责任和存货风险、定价权受限 | **净额法**（按佣金/手续费确认收入） |

### 考点 9：特殊交易 ★★★

- **附退货条款**：按预期不会退货的部分确认收入，退货部分确认**预计负债**（应付退货款）和**应收退货成本**；
- **授予知识产权许可**：区分**时段**（如持续提供更新）和**时点**（如一次性授权）；
- **售后回购**：
  - 远期回购/看涨期权（回购价格 < 原售价）→ 实质是**融资**，不确认收入；
  - 看跌期权（客户要求回购）→ 按**租赁**或**融资**处理，视回购价格而定；
- **预收款**：确认**合同负债**，待履约时确认收入。

### 考点 10：合同成本 ★★

| 成本 | 处理 |
| --- | --- |
| **合同履约成本** | 满足条件（与合同直接相关、增加企业未来用于履约的资源、预期能收回）的，资本化，按履约进度摊销 |
| **合同取得成本** | 预期能收回的**增量成本**（如销售佣金）资本化；摊销期不超过 1 年的，可简化为费用化 |

### 考点 11：列报 ★★

| 项目 | 含义 |
| --- | --- |
| 应收账款 | **无条件**收取对价的权利（仅取决于时间流逝） |
| 合同资产 | 已转让商品但收款权利**取决于时间之外的因素**（如其他履约义务完成） |
| 合同负债 | 企业已收或应收客户对价而**尚未向客户转让商品**的义务 |

## 三、关键分录

```text
1. 预收货款
借：银行存款
  贷：合同负债

2. 履行履约义务，确认收入
借：合同负债
  贷：主营业务收入
      应交税费——应交增值税（销项税额）

3. 建造合同（时段履约，投入法）
借：合同结算——收入结转
  贷：主营业务收入
借：主营业务成本
  贷：合同履约成本
借：应收账款 / 合同资产
  贷：合同结算——价款结算
      应交税费——应交增值税（销项税额）

4. 附退货条款
借：银行存款
  贷：主营业务收入（预期不会退货部分）
      预计负债——应付退货款（预期退货部分）
      应交税费——应交增值税（销项税额）
借：主营业务成本
    应收退货成本
  贷：库存商品
```

## 四、例题

**例 16-1（分摊交易价格）**

甲公司与客户签订合同，销售 A、B 两项产品，合同总价 100 万元。A 产品单独售价 60 万元，B 产品单独售价 60 万元。

**解析**：按单独售价比例分摊（60:60 = 1:1）：

- A 分摊 = 100 × 60/120 = 50（万元）；
- B 分摊 = 100 × 60/120 = 50（万元）。

**例 16-2（可变对价）**

甲公司销售设备，合同价 100 万元；若一年内设备运行良好，客户另支付 10 万元奖励。甲公司预计设备运行良好的概率为 80%。

**解析**：按期望值 = 10 × 80% = 8（万元）；且该金额极可能不会发生重大转回，交易价格 = 108 万元。

**例 16-3（建造合同，投入法）**

乙公司签订一项总价 1,000 万元的建造合同，预计总成本 800 万元，工期 2 年。第一年实际发生成本 240 万元。

**解析**：

- 履约进度 = 240 ÷ 800 = 30%；
- 第一年确认收入 = 1,000 × 30% = 300（万元）；
- 第一年结转成本 = 240（万元）；
- 合同毛利 = 60（万元）。

**例 16-4（主要责任人 vs 代理人）**

丙公司经营电商平台，客户下单后由第三方商家发货。丙公司不承担存货风险，仅收取 10% 佣金。客户支付 1,000 元，丙公司应确认收入（ ）。

**答案**：**100 元**（净额法，代理人）。

## 五、易错点

1. **五步法顺序不能乱**：先识别义务，再定价格，再分摊，最后确认。
2. **合同资产 ≠ 应收账款**：合同资产的权利取决于"时间之外的因素"。
3. **可变对价有"限制条件"**：极可能不发生重大转回的金额才能计入交易价格。
4. **保证类质量保证走"预计负债"**，服务类作为单项履约义务。
5. **主要责任人用总额法，代理人用净额法**。
6. **售后回购（回购价低于原售价）实质是融资**，不确认收入。
7. **时段履约的三个条件**满足其一即可，不要与"时点履约"混淆。
8. **合同取得成本**只有"增量成本"才资本化（如销售佣金）。

## 六、实务应用（会计岗位）

- **收入确认时点**：直接影响增值税纳税义务发生时间（先开票的，开票即纳税）；
- **合同负债与预收账款**：新准则下预收款计入"合同负债"，报表列示不同；
- **建造合同**：施工企业按履约进度确认收入，需建立成本归集和进度确认制度；
- **平台型业务**：判断总额法/净额法，直接影响收入规模和毛利率；
- **销售退回**：需根据历史退货率估计，影响收入和利润。

## 七、自测

**1.（单选）** 下列各项中，属于时段履约义务的是（ ）。
A. 销售现成商品
B. 为客户建造办公楼（在客户土地上）
C. 销售设备并转移所有权
D. 销售软件许可证（一次性授权）

**2.（判断）** 合同资产与应收账款的主要区别在于收款权利是否仅取决于时间流逝。

**3.（单选）** 企业销售商品并提供法定质量保证，该保证应作为（ ）处理。
A. 单项履约义务 B. 或有事项 C. 销售费用 D. 合同负债

**4.（计算）** 甲公司签订合同，销售设备（单独售价 80 万元）并提供安装服务（单独售价 20 万元），合同总价 90 万元。设备控制权转移时，应确认多少设备收入？

<details>
<summary>参考答案与解析</summary>

1. **B**。在客户土地上建造，客户控制在建商品，属于时段履约。
2. **√**。应收账款是无条件收款权（仅取决于时间），合同资产还取决于其他因素。
3. **B**。保证类质量保证按或有事项处理，确认预计负债。
4. 设备分摊比例 = 80/100 = 80%，设备收入 = 90 × 80% = **72 万元**。

</details>

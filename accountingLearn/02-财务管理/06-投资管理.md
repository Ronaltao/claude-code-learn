# 第 6 章 投资管理

> **教材位置**：第 6 章 ｜ **预计分值**：10–15 分 ｜ **常考题型**：单选、多选、计算分析、综合
> **一句话**：项目投资算"**现金流 → 折现 → 评价指标**"；证券投资算"**未来现金流折现求价值**"。NPV 是王道。

---

## 一、知识框架

```text
投资管理
├─ 投资分类（项目 / 证券；独立 / 互斥）
├─ 项目现金流量
│  ├─ 初始现金流量
│  ├─ 营业现金流量
│  └─ 终结现金流量
├─ 评价指标
│  ├─ 净现值（NPV）
│  ├─ 现值指数（PI）
│  ├─ 内含报酬率（IRR）
│  ├─ 回收期
│  └─ 会计报酬率
├─ 互斥项目决策
└─ 证券投资（债券、股票估值）
```

## 二、核心考点

### 考点 1：项目现金流量 ★★★★★

#### （1）初始现金流量

- 固定资产投资（含运输、安装）；
- 营运资金垫支；
- 原有资产变现价值及变现损失抵税（或收益纳税）。

#### （2）营业现金流量

```text
营业现金净流量（NCF）
= 营业收入 − 付现成本 − 所得税
= 净利润 + 非付现成本（折旧、摊销）
= (营业收入 − 付现成本 − 折旧) × (1 − T) + 折旧
```

> **折旧抵税**是项目现金流的重要来源：折旧本身不付现，但可以减少所得税。

#### （3）终结现金流量

- 固定资产残值回收；
- 营运资金收回；
- 处置资产的税负影响。

### 考点 2：净现值（NPV） ★★★★★

```text
NPV = Σ [NCFt ÷ (1 + i)^t] − 初始投资
```

- NPV > 0：项目可行（创造价值）；
- NPV = 0：刚好达到必要报酬率；
- NPV < 0：不可行；
- **互斥项目选 NPV 最大者**。

### 考点 3：现值指数（PI） ★★★★

```text
PI = 未来现金净流量现值 ÷ 初始投资现值
```

- PI > 1：可行；
- PI 反映**单位投资的效率**，适用于**独立项目**排序。

### 考点 4：内含报酬率（IRR） ★★★★★

```text
令 NPV = 0，求折现率 i
```

- IRR > 资本成本：可行；
- 计算：逐年测试 + 内插法；
- **互斥项目**中 IRR 可能与 NPV 结论冲突，**以 NPV 为准**。

### 考点 5：回收期 ★★★

```text
静态回收期 = 累计现金净流量达到初始投资的年限
动态回收期 = 累计折现现金净流量达到初始投资的年限
```

- 回收期越短越好；
- 缺点：**忽视回收期后的现金流**和**时间价值**（静态）。

### 考点 6：会计报酬率（ARR） ★★

```text
ARR = 年平均净利润 ÷ 平均投资额
```

- 基于会计利润，不是现金流；未考虑时间价值。

### 考点 7：互斥项目决策 ★★★★

| 冲突原因 | 处理 |
| --- | --- |
| 投资规模不同 | 以 **NPV** 为准 |
| 现金流时间分布不同 | 以 **NPV** 为准 |
| 寿命期不同 | 用**等额年金法**（年金净流量）比较 |

### 考点 8：债券估值 ★★★★★

```text
债券价值 P = Σ [I ÷ (1 + r)^t] + M ÷ (1 + r)^n
```

- I 为每期利息，M 为面值，r 为市场利率（必要报酬率），n 为剩余期限；
- 市场利率 > 票面利率 → 债券**折价**；反之**溢价**。

### 考点 9：股票估值 ★★★★★

| 模型 | 公式 |
| --- | --- |
| **零增长股** | P = D ÷ r |
| **固定增长股**（戈登模型） | P = D1 ÷ (r − g) = D0 × (1 + g) ÷ (r − g) |
| **阶段增长** | 分段折现 |

- D1 为下一期股利，g 为股利增长率，r 为必要收益率；
- 要求 **r > g**，否则模型无意义。

## 三、例题

**例 6-1（NPV）**

甲公司拟投资 1,000 万元购置设备，使用寿命 5 年，每年营业现金净流量 300 万元，期末无残值，资本成本 10%。已知 (P/A, 10%, 5) = 3.7908。

**解析**：

- 未来现金流现值 = 300 × 3.7908 = 1,137.24（万元）；
- NPV = 1,137.24 − 1,000 = **137.24 万元** > 0，项目可行；
- PI = 1,137.24 ÷ 1,000 = **1.14**；
- 静态回收期 = 1,000 ÷ 300 = **3.33 年**。

**例 6-2（债券估值）**

乙公司发行面值 1,000 元、票面利率 8%、期限 5 年的债券，每年付息一次，市场利率 6%。已知 (P/A, 6%, 5) = 4.2124，(P/F, 6%, 5) = 0.7473。

**解析**：

- 利息现值 = 80 × 4.2124 = 336.99（元）；
- 面值现值 = 1,000 × 0.7473 = 747.30（元）；
- 债券价值 = 336.99 + 747.30 = **1,084.29 元**（溢价发行）。

**例 6-3（股票估值）**

丙公司股票刚支付股利 2 元/股，预计股利年增长率 5%，投资者要求收益率 10%。

**解析**：P = 2 × (1 + 5%) ÷ (10% − 5%) = 2.1 ÷ 5% = **42 元/股**。

## 四、易错点

1. **折旧抵税**要计入现金流，但折旧本身不是现金流出。
2. **营运资金垫支**在初始流出，终结时收回。
3. **NPV 与 IRR 冲突时以 NPV 为准**。
4. **PI 适用于独立项目排序**，互斥项目仍看 NPV。
5. **债券价值与市场利率反向变动**。
6. **固定增长模型要求 r > g**。
7. **沉没成本**不应计入项目现金流；**机会成本**应计入。
8. 寿命期不同的互斥项目，要用**等额年金法**。

---

## 五、实务应用（会计岗位）

- **资本预算**：新设备、新厂房投资决策，NPV 是核心指标；
- **债券投资**：计算债券内在价值，判断是否值得买入；
- **股票估值**：股利折现模型用于长期投资分析；
- **项目后评价**：实际现金流与预算对比，评估投资效果。

## 六、自测

**1.（单选）** 某项目 NPV = 0，说明（ ）。
A. 项目亏损 B. 项目刚好达到必要报酬率 C. 项目不可行 D. 项目风险为零

**2.（判断）** 互斥项目决策中，若 NPV 与 IRR 结论冲突，应以 IRR 为准。

**3.（单选）** 市场利率高于票面利率时，债券应（ ）。
A. 溢价发行 B. 折价发行 C. 平价发行 D. 无法判断

**4.（计算）** 某股票下一期股利 1.2 元，股利增长率 4%，必要收益率 10%，股票价值为多少？

<details>
<summary>参考答案与解析</summary>

1. **B**。NPV = 0 表示刚好达到必要报酬率。
2. **×**。应以 NPV 为准。
3. **B**。市场利率高，债券价值低，折价发行。
4. P = 1.2 ÷ (10% − 4%) = **20 元**。

</details>

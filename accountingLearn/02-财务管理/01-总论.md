## 二、核心考点

### 考点 1：财务管理内容 ★★

| 内容 | 核心问题 |
| --- | --- |
| **投资** | 钱投到哪里（项目、证券） |
| **筹资** | 钱从哪里来（股权、债务） |
| **营运资金** | 日常资金怎么周转（现金、应收、存货） |
| **利润分配** | 赚的钱怎么分（股利政策） |

### 考点 2：财务管理目标 ★★★★★

| 观点 | 优点 | 缺点 |
| --- | --- | --- |
| **利润最大化** | 简单直观 | 未考虑时间价值、风险、投入资本 |
| **股东财富最大化** | 考虑时间价值和风险；可通过股价衡量 | 股价受多种因素影响；非上市公司难以衡量 |
| **企业价值最大化** | 考虑时间价值、风险、相关者利益；适用于非上市公司 | 企业价值难以准确计量 |
| **相关者利益最大化** | 兼顾股东、债权人、员工、政府等 | 目标多元，难以量化 |

> 现代企业财务管理**主流目标是股东财富最大化**（上市公司）或**企业价值最大化**（非上市公司）。

### 考点 3：利益冲突与协调 ★★★★★

#### （1）股东与经营者

| 冲突 | 协调机制 |
| --- | --- |
| 经营者可能追求在职消费、规避风险、短期行为 | **解聘**（约束）、**接收**（市场约束）、**激励**（股票期权、绩效股） |

#### （2）股东与债权人

| 冲突 | 协调机制 |
| --- | --- |
| 股东可能投资高风险项目、发行新债稀释债权价值 | **限制性借款**（合同条款）、**收回借款**、**停止借款** |

#### （3）大股东与小股东

- 协调机制：完善公司治理、累积投票制、独立董事、信息披露。

### 考点 4：财务管理环节 ★★

```text
财务预测 → 财务决策 → 财务预算 → 财务控制 → 财务分析 → 业绩评价
```

> **财务决策**是核心环节。

### 考点 5：财务管理体制 ★★

| 模式 | 特点 | 适用 |
| --- | --- | --- |
| **集权型** | 权限集中于总部 | 规模小、业务单一 |
| **分权型** | 权限下放 | 规模大、业务多元 |
| **集权与分权相结合** | 重大决策集权、日常经营分权 | 大多数企业 |

### 考点 6：金融环境 ★★★★★

#### （1）金融市场分类

| 分类标准 | 类型 |
| --- | --- |
| 交易期限 | 货币市场（≤1 年）、资本市场（>1 年） |
| 交易性质 | 发行市场（一级市场）、流通市场（二级市场） |
| 交易对象 | 股票市场、债券市场、外汇市场、衍生品市场 |

#### （2）利率的构成

```text
利率 = 纯利率 + 通货膨胀补偿率 + 风险报酬率
风险报酬率 = 违约风险报酬率 + 流动性风险报酬率 + 期限风险报酬率
```

| 组成 | 含义 |
| --- | --- |
| 纯利率 | 无通胀、无风险情况下的均衡利率 |
| 通货膨胀补偿率 | 弥补预期通货膨胀 |
| 违约风险报酬率 | 借款人不能按期还本付息的风险 |
| 流动性风险报酬率 | 资产变现能力差的风险 |
| 期限风险报酬率 | 期限越长，不确定性越大 |

### 考点 7：经济环境与法律环境 ★

- **经济环境**：经济周期、经济发展水平、宏观经济政策、通货膨胀；
- **法律环境**：公司法、证券法、税法、合同法等。

---

## 三、易错点

1. **利润最大化没有考虑时间价值和风险**，这是它最主要的缺点。
2. **股东财富最大化**通常用**股价**衡量，但股价受多种因素影响，不能完全反映企业价值。
3. **股东与经营者的协调**：解聘、接收、激励；**股东与债权人的协调**：限制性借款、收回借款、停止借款。
4. **财务决策**是财务管理环节的核心。
5. **利率构成**：纯利率 + 通胀补偿 + 违约 + 流动性 + 期限风险。
6. 货币市场 ≤ 1 年，资本市场 > 1 年。

---

## 四、实务应用（会计岗位）

- 财务经理做投资决策时，实际是在权衡"收益—风险—时间"；
- 预算编制是"财务预测 → 决策 → 预算"的落地；
- 与银行谈贷款利率时，利率构成决定了你能争取的空间（信用评级影响违约风险溢价）。

## 五、自测

**1.（单选）** 下列财务管理目标中，没有考虑时间价值和风险的是（ ）。
A. 利润最大化 B. 股东财富最大化 C. 企业价值最大化 D. 相关者利益最大化

**2.（多选）** 协调股东与经营者利益冲突的机制有（ ）。
A. 解聘 B. 接收 C. 激励 D. 限制性借款

**3.（单选）** 利率构成中，不属于风险报酬率的是（ ）。
A. 违约风险报酬率 B. 流动性风险报酬率 C. 通货膨胀补偿率 D. 期限风险报酬率

**4.（判断）** 货币市场是指交易期限在 1 年以上的金融市场。

<details>
<summary>参考答案与解析</summary>

1. **A**。
2. **ABC**。限制性借款是协调股东与债权人冲突的机制。
3. **C**。通货膨胀补偿率与风险报酬率并列，不属于风险报酬率。
4. **×**。货币市场 ≤ 1 年，资本市场 > 1 年。

</details>

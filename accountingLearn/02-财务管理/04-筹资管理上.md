# 第 4 章 筹资管理（上）

> **教材位置**：第 4 章 ｜ **预计分值**：5–8 分 ｜ **常考题型**：单选、多选、判断
> **一句话**：本章讲"**钱从哪来**"——股权、债务、租赁、衍生工具，重点是**各类筹资方式的优缺点和适用场景**。

## 二、核心考点

### 考点 1：筹资动机与分类 ★★

**动机**：扩张性、调整性、混合性。

| 分类标准 | 类型 |
| --- | --- |
| 资金来源 | 股权筹资、债务筹资 |
| 资金使用期限 | 长期筹资、短期筹资 |
| 是否通过金融机构 | 直接筹资、间接筹资 |
| 资金来源范围 | 内部筹资（留存收益）、外部筹资 |

### 考点 2：股权筹资 ★★★★

| 方式 | 特点 |
| --- | --- |
| **吸收直接投资** | 非股份制企业；手续简单；资本成本较高 |
| **发行普通股** | 股份制企业；永久性资本；分散控制权 |
| **留存收益** | 内部积累；无发行费用；资本成本最低（股权中） |

**股权筹资优点**：

- 永久性资本，无固定还本付息压力；
- 增强企业信誉和借款能力；
- 财务风险小。

**股权筹资缺点**：

- 资本成本较高（股利不能抵税）；
- 分散控制权；
- 可能稀释每股收益。

### 考点 3：债务筹资 ★★★★

| 方式 | 特点 |
| --- | --- |
| **银行借款** | 速度快、成本低、弹性好；限制条件多 |
| **公司债券** | 期限长、利率固定、可抵税；发行门槛高 |
| **融资租赁** | 融资与融物结合；租金较高 |
| **商业信用** | 应付账款、应付票据、预收账款；成本低但期限短 |

**债务筹资优点**：

- 资本成本较低（利息可抵税）；
- 不分散控制权；
- 有财务杠杆效应。

**债务筹资缺点**：

- 财务风险大（固定还本付息）；
- 限制条件多；
- 筹资数额有限。

### 考点 4：融资租赁 ★★★★

| 形式 | 说明 |
| --- | --- |
| **直接租赁** | 出租人购买设备租给承租人 |
| **售后回租** | 企业将资产卖给出租人再租回 |
| **杠杆租赁** | 出租人只投入部分资金，其余靠借款 |

**租金计算**（等额年金法）：

```text
年租金 = 租赁设备价值 ÷ (P/A, i, n)
```

> 租金包括设备价款、利息、手续费等，通常高于银行借款成本。

### 考点 5：衍生工具筹资 ★★★

| 工具 | 特点 |
| --- | --- |
| **可转换债券** | 债券 + 转股权；票面利率低；转股后稀释股权 |
| **认股权证** | 按约定价格认购股票的权利；常用于附赠 |
| **优先股** | 优先分配股利、优先清偿；通常无表决权；股利不能抵税 |

### 考点 6：筹资方式比较 ★★★★

| 维度 | 股权筹资 | 债务筹资 |
| --- | --- | --- |
| 资本成本 | 高 | 低（税盾） |
| 财务风险 | 低 | 高 |
| 控制权 | 分散 | 不分散 |
| 抵税 | 股利不能抵税 | 利息可抵税 |
| 期限 | 永久 | 有期限 |

## 三、例题

**例 4-1（融资租赁租金）**

甲公司采用融资租赁方式租入设备，设备价值 500 万元，租期 5 年，年利率 8%，每年末等额支付租金。已知 (P/A, 8%, 5) = 3.9927。

**解析**：年租金 = 500 ÷ 3.9927 = **125.23 万元**。

**例 4-2（可转换债券）**

某公司发行可转换债券，面值 1,000 元，票面利率 2%，转股价格 20 元/股。若股价上涨至 30 元，投资者转股后的价值为（ ）。

**解析**：每张债券可转股 1,000 ÷ 20 = 50 股；转股价值 = 50 × 30 = **1,500 元**。

## 四、易错点

1. **股权资本成本高于债务资本成本**（股利不能抵税、股东承担更大风险）。
2. **债务利息可以抵税**，这是债务筹资成本低的重要原因。
3. **优先股股利不能抵税**，且通常无表决权。
4. **融资租赁租金通常高于银行借款**。
5. **留存收益资本成本低于新发行普通股**（无发行费用）。
6. **可转换债券**票面利率低于普通债券，但转股会稀释股权。
7. 商业信用**不是免费的**（放弃现金折扣有成本）。

---

## 五、实务应用（会计岗位）

- **筹资方案选择**：比较股权与债务的资本成本、财务风险、控制权影响；
- **融资租赁**：适合资金不足但需要设备的企业，租金可税前扣除；
- **可转债**：适合成长型企业，低息融资 + 延迟股权稀释；
- **资本结构**：筹资决策最终影响 WACC 和公司价值。

## 六、自测

**1.（单选）** 下列筹资方式中，资本成本通常最低的是（ ）。
A. 发行普通股 B. 银行借款 C. 留存收益 D. 吸收直接投资

**2.（判断）** 优先股股利可以在企业所得税前扣除。

**3.（单选）** 融资租赁的三种形式不包括（ ）。
A. 直接租赁 B. 售后回租 C. 杠杆租赁 D. 经营租赁

**4.（多选）** 债务筹资的优点有（ ）。
A. 资本成本较低 B. 不分散控制权 C. 财务风险小 D. 利息可抵税

<details>
<summary>参考答案与解析</summary>

1. **B**。债务成本最低（利息抵税）。
2. **×**。优先股股利不能抵税。
3. **D**。经营租赁不属于融资租赁形式。
4. **ABD**。债务筹资财务风险大，C 错误。

</details>

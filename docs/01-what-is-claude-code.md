# 01 · 什么是 Claude Code

> 本节目标：用 5 分钟搞清楚 Claude Code 到底是什么、能帮你做什么、不能做什么。

## 是什么

**Claude Code 是 Anthropic 官方的"命令行 AI 编程助手"。**

你在终端里启动它，然后用**大白话**告诉它你想干什么，它就能：

- 📖 **读你的代码** —— "解释一下这个项目是怎么跑起来的"
- ✏️ **改你的代码** —— "把这个函数改成支持分页"
- 🏃 **跑命令** —— 自动执行测试、安装依赖、运行脚本
- 🔍 **查资料** —— 搜代码库、上网查文档
- 🌿 **管 Git** —— 写 commit、开分支、提 PR
- 🧠 **理解整个项目** —— 不只是一段代码，而是跨多个文件协作

简单说：**它像一位坐在你旁边、能直接动手的结对编程工程师**，而不只是一个聊天机器人。

## 和 ChatGPT / 网页版 AI 有什么区别？

这是新手最常见的疑问。关键区别在于 **Claude Code 能直接操作你的电脑和项目**：

| | 网页版 AI 聊天 | Claude Code |
|---|---------------|-------------|
| 看你的代码 | 你得手动复制粘贴 | 它**自己读**你项目里的文件 |
| 改代码 | 给你一段代码，你自己粘回去 | 它**直接修改**你的文件 |
| 跑测试 | 做不到 | 它**自己运行**并看结果 |
| 多文件协作 | 很难 | 天生擅长跨文件理解和修改 |
| 上下文 | 每次对话重新解释项目 | 通过 `CLAUDE.md` **记住**你的项目 |

一句话：网页版是"问答"，Claude Code 是"动手"。

## 它在背后是怎么工作的

理解这个心智模型，能让你用得更顺：

1. 你提出需求（自然语言）。
2. Claude **制定计划**：要读哪些文件、改哪里、跑什么命令。
3. 它**调用"工具"**去执行 —— 读文件、写文件、运行命令、搜索等。
4. 每个**有风险的操作**（比如改文件、删东西、跑命令）默认都会**先问你**是否同意。
5. 它看到结果后**继续推进**，直到任务完成。

> 🔑 记住第 4 点：**默认情况下它不会偷偷改你的东西**，危险操作都会征求你同意。安全机制在 [第 06 节](06-permissions.md) 详讲。

## 它不擅长 / 做不到什么

新手要有合理预期，避免踩坑：

- ❌ **不是万能的**：复杂的架构决策、模糊不清的需求，它可能跑偏 —— 这时要用[计划模式](07-plan-mode.md)先对齐。
- ❌ **会犯错**：它写的代码不一定对，**务必自己 review、跑测试**。把它当"能力很强但需要你把关的初级工程师"。
- ❌ **不知道你心里想的**：需求越清楚，结果越好。模糊的"优化一下"不如"把这个循环改成用字典查找来提速"。
- ⚠️ **可能花钱**：它通过 API 工作，长对话会消耗 token（`/cost` 可查用量）。开新任务记得 `/clear`。

## 什么时候用它最爽

- 接手一个陌生项目，想快速搞懂结构 → "带我过一遍这个项目"
- 修一个不知道根因的 bug → "登录报错，帮我定位"
- 写样板代码 / 测试 / 文档 → "给这个模块补单元测试"
- 重复性重构 → "把所有 print 换成 logging"
- 写 Git commit、PR 描述

# 10 · Skills 技能

> 本节目标：了解什么是 Skills，它如何把"重复的专业流程"封装成 Claude Code 可随时调用的能力。这是进阶玩法，入门阶段了解概念即可。

## 是什么

**Skill（技能）** 是一段打包好的"专业知识 + 操作步骤"，告诉 Claude Code **在某类任务上该怎么做**。当你的请求匹配到某个技能，Claude Code 就会按技能里写好的最佳流程来执行。

类比：技能就像给员工的"标准作业手册（SOP）"。普通员工凭直觉做事，有了 SOP 就能稳定、专业地完成特定任务。

举例，Claude Code 可能内置或可安装这类技能：
- **代码审查**：按固定维度系统性 review 改动
- **深度研究**：多源搜索 + 交叉验证 + 输出带引用的报告
- **PR 审查 / 安全审查**
- **配置助手**：帮你改 settings.json、键位等

## 技能 vs 普通提问

| | 普通提问 | 用技能 |
|---|---------|--------|
| 流程 | 临场发挥，每次可能不同 | 按预设的专业步骤，稳定 |
| 质量 | 取决于你怎么问 | 内置了领域最佳实践 |
| 触发 | 你详细描述 | 一句话/一个命令触发整套流程 |

## 怎么用

### 看看有哪些技能
启动后，可用的技能通常会以"斜杠命令"形式出现。输入 `/` 看列表，或直接问：
```
你现在有哪些可用的技能（skills）？
```

### 触发技能
两种方式：
1. **直接描述任务**，匹配上就自动用，例如"帮我审查一下这次的代码改动"可能触发代码审查技能。
2. **用斜杠命令显式调用**，例如 `/review`、`/security-review`（取决于你装了哪些）。

### 自己做技能（进阶）
技能本质是放在特定目录下的说明文件（描述"什么时候用、怎么做"）。你可以为团队反复出现的流程自定义技能，比如"按我们公司规范生成接口文档"。这属于高级定制，新手先会用内置的即可。

> 📌 相关概念：自定义**斜杠命令**（`.claude/commands/`）是更轻量的封装方式，适合简单的提示词复用；Skills 则适合更复杂、更结构化的能力。

## 什么时候关注它

- 入门期：**知道有这回事就行**，先把前 9 节的基本功练熟。
- 进阶期：当你发现自己反复给 Claude 同样一大段指令时，就该考虑把它做成技能或自定义命令了。

## 动手试一试

1. 启动 `claude`，问它：
   ```
   列出你当前可用的技能，并说明每个大概什么时候用
   ```
2. 如果有 `/review` 之类的命令，先随便改本项目一个文件，再试着触发代码审查，体会"按专业流程办事"和"随便问问"的差别。

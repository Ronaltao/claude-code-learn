# 05 · 斜杠命令

> 本节目标：认识在对话框里以 `/` 开头的"斜杠命令"，掌握几个每天都用的高频命令。

## 是什么

**斜杠命令（Slash Commands）** 是 Claude Code 的内置快捷指令。在输入框里打 `/`，会弹出命令列表。它们不是发给 AI 的"提问"，而是直接控制 Claude Code 本身的"开关和工具"。

类比：和 AI 聊天是"对话"，斜杠命令是"遥控器上的按钮"。

## 怎么用

输入 `/`，上下键选择，回车执行；或直接打全名比如 `/clear` 回车。

### 新手必会的几个

#### `/help` —— 万能帮助
忘了有啥命令？打开它看全部。

#### `/clear` —— 清空上下文 ⭐最常用
开始一个**全新任务**前用它。把之前的对话清空，让 Claude 不被旧上下文干扰，**更快、更准、更省钱**。

> 经验法则：换任务 = 先 `/clear`。

#### `/init` —— 一键生成 CLAUDE.md
在一个新项目里运行，它会自动分析代码库，生成一份 `CLAUDE.md`（项目记忆）。新接手项目时强烈推荐。详见 [第 08 节](08-claude-md.md)。

#### `/model` —— 切换模型
在更强（更慢更贵）和更快（更便宜）的模型间切换。复杂任务用强的，简单任务用快的。

#### `/config` —— 设置
改主题、改各种偏好。

#### `/cost` —— 看花了多少
显示本次会话的 token 消耗，建立成本意识。

#### `/permissions` —— 权限管理
查看和调整"哪些操作需要批准"。详见 [第 06 节](06-permissions.md)。

## 斜杠命令 vs 直接提问 vs 其它符号

新手容易混淆几个特殊符号，一张表理清：

| 你输入 | 含义 | 例子 |
|--------|------|------|
| 普通文字 | 发给 AI 的需求 | `帮我修复登录 bug` |
| `/` 开头 | 斜杠命令（控制 Claude Code） | `/clear` |
| `@` 开头 | 引用文件 | `@src/auth.py` |
| `!` 开头 | 直接运行 shell 命令 | `!git status` |
| `#` 开头 | 把内容追加进 CLAUDE.md 记忆 | `#本项目用 pytest 测试` |

## 小贴士：自定义斜杠命令

进阶玩法：你可以把常用提示词存成自己的斜杠命令（放在 `.claude/commands/` 目录里）。比如做一个 `/中文提交` 来一键生成中文 commit。这属于高级内容，入门阶段了解即可，[第 10 节 Skills](10-skills.md) 会涉及相关概念。

## 动手试一试

启动 `claude` 后：

1. 输入 `/help`，浏览全部命令。
2. 输入 `/cost`，记下当前消耗。
3. 随便问它一个问题，再 `/cost`，看消耗变化。
4. 输入 `/clear`，体会"清空重来"。
